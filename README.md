# 畫中有案 · 榜下尋人

《宮中鬧元宵》的現行介面是整個遊戲的標準。《在人群中聽樂》現行 v1.2 已納入原版遊戲的首頁入口及歷史畫作選單：尋找四位人物、探索六類見聞，並在原畫中連起樂隊、儀仗與吉祥彩牆。主應用路由 `#kangqu-listening`，畫作選單 `#historical-paintings`。見 [現行整合設計](docs/chapters/kangqu-listening-integrated-v1.2.md)與[人物對白紀錄](docs/chapters/kangqu-listening-dialogue-v1.2.md)。本地頁面操作與動畫接縫尚未實測；線上版本未推送或部署。

一個以人物圖片為目標的古風尋人網頁遊戲。原創「科舉放榜日」長卷參照《清明上河圖》的城市風俗畫風；實際完成時間仍待學生實測。

先由滿版引言頁入畫：直排題字，手動推進三幕，可返回。最後一幕提供要找的人物去背圖，只顯示人物及手中物件，玩家自行按「記住了，開始尋人」才入畫；略過故事也會先到看圖這一步。入畫後人物圖收起，不提供再次查看的入口。

先記住人物圖，再在畫中尋找，點中便完成，零條或部分線索都能成功。找不到時，可逐步查看特徵、地標與區域文字提示，或自由向畫中人問訊。抄榜人、茶攤掌櫃與榜前圍觀者的證詞都是可選幫助。預設為凝神模式，自行移動觀察範圍；畫卷灰白，只有觀察範圍呈原畫淡彩。覺得太難可按右上「彩色」顯示整幅彩畫，再按「凝神」返回；不會標記線索。

## 啟動

本機檔案版可直接開啟 `public/index.html`；封面下方含「宮中鬧元宵」「在人群中聽樂」與畫作選單。此檔由 `npm run build` 後的 `scripts/package-local-home.py` 同步生成，沿用原版 React 程式及共用樣式。不要只開 `public/` 目錄或將章節文件加上選單 hash。尚未實際驗證 file 方式下所有瀏覽器功能。

需要 Node.js 22.18 或更新版本。

```sh
npm install
npm run dev -- --port 5188
```

瀏覽器開啟 <http://127.0.0.1:5188/>。

```sh
npm test
npm run build
npm run preview -- --port 5189
```

## 操作

- 拖曳移動畫卷；滾輪、雙指或按鈕縮放。
- 點擊畫中人物問訊；茶攤掌櫃恢復提供書箱證詞。
- 預設凝神模式；右上「彩色」切至全彩，再按「凝神」切回：滑鼠移動觀察範圍，拖曳畫卷；手機單指拖動光區，雙指移動或縮放畫卷。F 切換模式，方向鍵移動光區（Shift 加速），Esc 轉為彩色；仍可點選人物。閱讀、問訊及打開選單時保留玩家所選模式；重玩、換卷預設凝神。
- 開始前先看人物圖，入畫後不再提供；找到目標即完成，不必收齊線索。重玩時先重新看圖再開始。
- 右下「找不到？看看提示」分三層：外觀、地標、區域；選擇「帶我看區域」才會移動鏡頭，不標記答案人物。提示留在畫面供閱讀，直到收起或繼續互動。
- 線索簿標明可選；未收錄項目也提供來源小像和身份，主要線索可點擊查看問訊方向。
- 左下角線索簿可展開重讀，保持場景可見；點錯顯示短暫文字；完成後可重玩。
- 畫作開啟即填滿網站視窗；右上角可額外進入瀏覽器全螢幕。
- 右上角可自行開啟輕柔古風撥弦純音樂；曲末交疊淡出淡入，離開頁面時靜音，閱讀證詞時降低音量。
- 茶壺蒸汽有少量微動，可獨立關閉；系統設定減少動態效果時預設停用。
- 「⋯」內可縮放、回到卷首、查看指南或自行打開科舉小知識。畫作開啟即鋪滿網站視窗，左右拖曳探索各段人物。
- 可自行打開科舉小知識，先單獨閱讀資料與史料來源，按「讀完了，答一題」才切換至三選一題；可返回資料重讀；答錯可重選，答對顯示解說並完成閱讀。同一局保留完成狀態，重玩則重置。
- 任務說明預設收起，左上只保留尋人任務；開局鏡頭先集中在一段畫卷，仍可拖曳探索全卷。底部操作提示在入畫後顯示，探索後消失。
- 放大以滑鼠或雙指中點為中心，最多 175%；鍵盤 ＋／－縮放，Home 回到卷首；縮小下限維持滿版。
