# 三處皇帝身影：尋獲後的動作樣段 v2

2026-10-16。入口：`http://127.0.0.1:5198/#emperor-preview`。

## 修正原因與方法

使用者指出 v1 三段皆有剪紙感、殘影／色塊／接縫、動作過小或不自然。v1 以原畫頭部和手掌獨立轉動，缺少肩頸與袖臂連帶；局部修補亦可能在關節間露出。該播放方式已被 v2 取代。

v2 使用每人一條四姿態透明圖：原姿勢 → 轉頭 → 抬手及袖臂同動 → 回復。人物完整一起變換姿態，取消獨立頭部與手掌裁片。每段約4秒，完成後移除圖層、回復原畫，再接原有短對白。

- 第一處：坐看爆竹，朝庭前轉頭並抬袖示意。
- 第二處：站看街市，轉頭、腰旁袖臂向外展開。
- 第三處：坐看表演，轉頭、袖臂向空位展開；演繹圖層水平映轉，讓手勢避開右側帳幔，這是演繹構圖安排。

每位角色以原畫尺寸設定固定顯示比例，各姿態以袍底／腳底錨點對位。原畫欄杆和帳幔透過前景裁切保留遮擋。新底圖只在舊人物輪廓內以羽化遮罩顯示，其他原畫維持原來圖層。透明姿態圖顯示時對alpha邊緣小幅收縮，減輕生成邊緣雜點；素材原檔不改寫。

## 素材與事實分界

人物姿態與隱藏底圖由內置 image_gen 依原畫生成，並非原畫像素的直接動作復原；衣紋、面貌、身形與原畫有摹繪差異。頁面標示「人物動作摹繪，眉眼、衣飾與姿勢以原畫為準」。短對白仍為遊戲虛構。正式尋人應以原畫面貌為準。

此版仍為獨立預覽，尚未接入正式章節尋獲流程。正式整合時只應在玩家找到並確認皇帝後播放，不在尋找期間自動播放。

## 實際檢視與限制

已在內置瀏覽器逐段觀看新版原位播放與原畫恢復，保存三段抬手姿態。修正SVG保持比例的預設行為後重新查看第一段；第三段原先手勢被帳幔遮住，改朝空位展開後已重播查看。

四姿態依序切換，尚非高幀率連續人物動畫；每次姿態切換及進出原畫仍可能察覺摹繪差異。原畫高清分片的既有色差和接縫仍可見，沒有藉此改寫原畫。效果與人物相似度供使用者審閱，未獲定稿確認。

減少動態時只保留原畫約1秒後接對白；素材載入失敗保留原畫及重試。這兩項未實際操作檢視。未新增或執行測試套件、建置或手機檢視。
