原畫：`public/art/lantern-festival/detail-7.jpg`。三位人物以完整四姿勢透明圖組原位播放五秒：綠衣鼓手先起拍，褐衣演出者展袖抬腿，持幡者隨後調整長幡。固定腳底位置，沿用長卷投影、提示卡及見聞冊介面。背景只在原人物範圍修補，黃衣人物與前方紅袍人物以原畫遮擋層保留。

點中任一動畫人物直接播放，結束後收入既有「演出中的裝扮」類別；重播不增加數量。預覽見聞冊含上一樣段的火爐，共七類，收藏只保留於當次頁面。

動作次序、鼓點與展袖的配合為遊戲情景演繹，不主張原畫記錄了這一連續動作，未新增聲音。人物姿勢圖組為生成素材，畫風、細節與原畫仍有差異；原畫在片段結束後完整恢復。

素材與提示保存於 `generation-records.json`，使用的 PNG 保存於 `public/art/animations/lantern-theatre/`。首輪含袒腹人物的素材請求遭生成服務內容檢查攔截，改為保留該人物原畫，只生成三位衣着完整的演出者。
