# 引言頁與長卷細節更新

## 引言頁

使用者否定大型書籤式開場紙箋，確認改為滿版引言頁。畫作仍作為背景，左側淡絹色漸層提供文字對比，沒有頁首或頁尾色帶、卡片框線及常駐任務進度。直排「榜下尋人」、小印章、短引言及一個「入畫尋人」入口組成開場。

按下入口後，引言在 600ms 內淡出；系統減少動態效果時直接切換。遊戲中的任務改為小型控制，顯示題名、0/2 證詞進度及可展開的短說明。線索簿、提示及聲音等探索控制在入畫後才出現。拖曳提示的計時亦從入畫後開始。

## 高解析美術方向

原主圖為 2172 × 724。新美術以原圖三個正方形分區作為重製對位，保留榜牆、茶攤、橋頭及人物的視覺關係，補充面孔、衣摺、筆、茶壺與書箱等細節。素材由內建 imagegen 製作。

美術生成目標尺寸與實際回傳尺寸分開記錄，不將簡單放大稱為原生高解析。每個區段接入前均需審視其人物位置與左右邊界。

## 第七輪：循序敘事、淡彩與藏人

使用者認為引言一次交代太多、美術色彩過鮮，目標書生並排站在空地上過於突出。因此調整為：

- 引言分為三幕：放榜日的背景、人潮中的走散、書童的委託。每幕只有兩行短句，由玩家手動推進，可返回或略過；沒有自動播放、打字動畫或強制等待。
- 最後一幕只提供第一個行動「向抄榜人問訊」。遊戲中的小型任務控制按證詞逐步更新為掌櫃、尋人；若先找到掌櫃，則引導回榜牆，不強制固定訪問順序。
- 保留高清分段及滿版鏡頭。全卷與證人小像共用 CSS 色彩呈現：`saturate(.38) sepia(.12) contrast(.9) brightness(1.035)`，壓低鮮藍、粉紅與橙色，減輕墨線的硬對比；沒有對圖片做模糊或降低解析度。
- 以內建 imagegen 編輯橋頭段，移除原本並排三人的空地構圖，補入行人，三名候選書生分散到不同群組。正解書生縮小、轉入橋頭人群，部分腿部受遮擋，但衣衫與方形書箱仍可辨認。新版原始素材是 `public/art/hd/bridge-v2.png`，尺寸 1254 × 1254；全卷的淡彩效果亦包含網站的統一色彩呈現，不宣稱下載的原始 PNG 已套用 CSS 色彩。
- 抄榜人及掌櫃位置保持不變，三名候選書生的熱區依新版美術重新對位。兩條證詞仍為青衫、方形書箱及橋頭去向。

提示保存於 `docs/art/bridge-v2-concealment-prompt.txt`；舊橋頭素材 `bridge.png` 保留作比較。未新增或執行測試；正式建置與 diff 空白檢查通過，已查看三幕引言及新版橋頭的實際瀏覽器畫面。
