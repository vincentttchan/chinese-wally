# 開始前看圖，入畫後尋人（2026-10-06）

實測：學生不知道要找誰，畫中人物太多，也不知道需要找線索。使用者先確認提供人物圖、找到便成功、線索可選，隨後修訂為「人物圖只在開始前提供，入畫後不再提供」。本文件描述最新流程。

## 介面設計

沿用原畫和紙箋；人物圖改用透明背景的去背 PNG，只顯示目標人物及持物，避免鄰近人物與攤位干擾；來源及最終提示見 `docs/art/target-cutouts.md`。開始前提供較大圖片供記憶，不設定觀看倒數，由玩家自行決定何時入畫。遊戲內只保留任務、可選線索簿與文字提示，不保留目標圖片或重新看圖入口。

- 紙色 `#f5efdf`、墨色 `#353c32`、草綠 `#485a47`、印朱 `#954c37`、紙邊 `#c6bb99`。
- 沿用 Noto Serif TC／宋體。開始按鈕縮短字距，讓文字在小螢幕保持一行。
- 圖片只出现在引言最後一幕。入畫即從介面移除，不等淡出動畫結束。
- 入畫後左上是精簡的尋人任務，右上保留工具，底部保留可選線索簿與求助。

```text
開始前：故事 → 人物圖片 → 玩家按「記住了，開始尋人」
入畫後：[尋人任務]             [聲音][全螢幕][設定]

                    古畫搜尋區域

       [線索簿 · 可選]          [找不到？看看提示]
```

## 流程與規則

1. 略過故事仍先到人物圖，不會跳過看圖而直接開始。
2. 開始後不再顯示目標圖片；文字提示不要求學生再看圖片。
3. 點中目標立即完成，零條或部分線索均可；錯選提示不符的特徵。
4. 求助依序提供外觀、地標、區域文字。第三步由學生主動點擊才移鏡，不標記答案。
5. 線索簿明示所有線索可選；未收錄項目顯示來源，可主動查看如何找到該來源。
6. 廟會問訊可沿「餅攤婆婆 → 扇攤 → 孩子」串連，但不強制依順序走訪。
7. 結局不假設學生曾收集任何線索。重玩清除筆記與提示，先返回人物圖，確認後再開始。

兩卷均採用上述規則。人物記憶負擔、辨識度與實際完成時間仍需學生實測。
