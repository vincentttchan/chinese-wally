# 河道與虹橋段人物／線索人工盤點

範圍：原畫 x=12000–23999、y=0–1800；來源為 `public/art/qingming/tile-04.jpg`、`tile-05.jpg`、`tile-06.jpg`。座標均為原畫像素，非縮放後畫面。人物邊界按可見身體記錄，不推補被屋簷、船篷或同伴遮住的身體。

已閱讀 `AGENTS.md` 與章節製作標準。本次只製作盤點資料、原畫裁圖及供覆核的 SVG，未修改遊戲程式或介面，未執行測試。

## 實際查看

三張4000×1800原畫圖均拆成四段約1000px寬裁圖；中段保留左右100px重疊。已逐一用圖像工具查看這十二段；另放大查看 tile04右側泊船／行進船、tile05左側牽纜人物，並補看虹橋背後頂部窄帶。沒有以猜測格點或整群大熱區代替個人。

紅框＝可辨人物；灰框及問號＝不明人形候選；藍框＝物件／既有主線觀察區。框旁三位數是對應 id 最後三位；紅藍數字各自編號。SVG以相鄰原畫裁圖為底，不改動畫面。

## 記錄結果

- 人物候選共 314 項：311 位可辨人物候選可互動，3 項不明人形候選暫不互動。
- 物件／觀察區共 64 項。
- 十二段均有獨立檢視索引及人數。

人物的 name 是中性辨認標籤；evidence 是畫中可見位置與姿勢；replies 全屬遊戲虛構短句，並非人物真實語錄。未推定人物職業、船貨內容、身份、出身或歷史場景意義。部分短句按相似姿勢共用句式，但每人仍有獨立 bounds、id 與三句回應。

物件盤點包含舟船、橋邊攤位、桌攤、店面、掛牌、輪車、轎輿、擔籃及杆索裝置。跨裁圖的同一艘長船合併為一項；各船上的人物各自保留。未把遠處舟船歸入虹橋收藏。僅橋與相鄰河面／橋西攤販的實例登記 `rainbow-bridge`，同類由主程式去重。

`landmark-bridge`、`bridge-boat`、`bridge-people`、`bridge-stalls` 以 existingId 連回既有資料。其中 bridge-boat、bridge-people 是主線必經的集合觀察區，不算個人；集合內已另列逐人記錄。紙馬鋪、酒樓、客店、香鋪、醫藥鋪的五組既有店鋪線索均不在本段，不擅自對上無關店面。

## 已知限制與覆核重點

- 大部分人物身體可辨，頭部墨線仍細；名稱只寫衣姿與位置，不能視為職業考證。
- 3項不明人形候選列 excluded，分別為031桌後墨線、067遠舟短墨線、189舟艙框架交疊；三者均不能確認獨立頭肩，理由逐項保存。清楚的頭肩人物即使微小或遮擋，也保留互動。
- 虹橋密集人物與船上繩杆交叉處，矩形可重疊。這是手動候選邊界，導入前應按注記原畫覆核，不能用此盤點宣稱已完成互動重疊處理。
- x=12000及24000接縫出現裁去一部份身體／船身的情況；本段按可見中心分配，需與相鄰段合併時做接縫覆核。
- 原圖縮放／色差保持原樣；沒有生成或補畫任何細節。
- 未做互動、載入、學生試玩、裝置或對白排版檢查；本報告只描述實際原畫視覺盤點。

## 接縫補看（追加）

實際另查看12000、16000、20000、24000四張全高接縫原畫；再看20000附近橫向拼接原畫及24000人物放大裁圖。046、051、054原來分開的船篷／船舷已確認屬同一艘長舟，合併至046。立桅篷舟補回15958–16000的船尾。301補全被棚柱遮住的可見身體；318新增屋內桌旁坐姿人物。原302確認為戴寬帽行人，完整可見框為[23972,263,24034,380]，中心24003屬相鄰段，已移出本段人物表，供主盤點合併。人物總數維持314，物件減為64。這些是原畫視覺補看，沒有執行測試。

## 微小人物覆核（追加）

針對原54項 excluded，製作七張逐項標ID的原畫裁圖檢視頁（excluded-review-0至6.jpg），各局部放大約3倍並實際逐張查看。原以尺寸判定的排除規則已撤銷：51項具有可定位的獨立頭部／肩頭／身體，改為 interactive。橋欄後的人物與其餘人物採同一可辨標準，不因遮擋或熱區密集而移除；未補畫或推測隱藏身體。只保留031、067、189三項無法分離確認人形的墨線候選，逐項寫明理由。最終314項中311可互動、3不明候選 excluded；人物表是候選盤點資料，尚未完成遊戲互動驗證。
