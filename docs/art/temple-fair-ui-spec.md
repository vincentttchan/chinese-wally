# 廟會尋蹤介面與美術規格

以使用者已确认的廟會尋皇帝草案、現有遊戲介面和新長卷作實作規格。

- 容器：單一滿版可拖曳畫卷，桌面與手機均維持 cover 下限，放大上限 175%。
- 背景：暖絹紙，由實際美術提供，畫面不加全幅色罩；現有共用淡彩 filter 保留。
- UI：沿用 `--paper: #f5efdf`、`--ink: #353c32`、`--green: #485a47`、`--red: #954c37`；紙箋與手繪圖示使用現有點陣美術。
- 字體：Noto Serif TC / Songti TC，既有直排 52–76px 引言題字、14px 故事、13px 任務、12px 按鈕與 24px 閱讀標題。
- 主畫面：左上小型「廟會尋蹤 / 悄悄辨認微服的皇帝 / 0/3」任務；右上音樂、全螢幕、更多；左下線索簿；右下三層提示。手動展開任務與線索後才顯示紙箋。
- 引言：三頁「廟會正盛」「便服之中」「悄悄尋君」，手動前進、返回、略過；保留原有排版。底部以小型兩卷選擇提供獨立入口。
- 證據：證詞、物件與觀察都用現有紙箋，依來源顯示標籤；小像裁取自同一長卷。未取得的來源姓名和小像隱藏。
- 解答：看客目光、補過的扇骨和沾粉右袖皆在美術中可見，熱區以成圖定位，不顯示永久標記。
- 提示：前兩層只有思路與場景方向，第三層才移動到廣泛區域；不畫答案箭頭。
- 結局：「人群中的天子」，簡短解說三條證據；可閱讀廟會知識、重玩、另展第一卷。
- 閱讀：先資料後三選一，錯答可重選或返回資料，答對顯示解說。
- 動效：延續克制紙箋淡入、畫卷拖動慣性和點中後短暫印記；廟會蒸汽按新畫位置定位。
- 音樂：沿用現有本地古風配樂與閱讀時降低音量。

實際畫作及其圖像生成提示保存在同目錄，互動座標需於美術完成後記錄。
