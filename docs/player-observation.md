# 由玩家控制的凝神觀察

2026-10-06：撤回點擊後揭布與圖片切換試作，集中於玩家可隨時使用的觀察操作。主畫作、滿版與左右探索維持原有設計。預設凝神模式，灰白底畫中只有玩家觀察範圍呈原畫淡彩。覺得太難時，可按右上「彩色」顯示整幅彩畫，再按「凝神」切回。

## 操作

- 入畫自動使用凝神模式；右上按鈕顯示「彩色」，點擊後改為全彩，按鈕變為「凝神」。F 切換，Esc 轉為彩色。
- 滑鼠移動觀察範圍；桌面拖曳仍移動畫卷，滾輪縮放。
- 手機單指拖動觀察範圍，雙指移動或縮放畫卷；短按仍可選人物。
- 畫卷獲得鍵盤焦點時，方向鍵每次移動光區 28 px，Shift 為 60 px。鍵盤選取人物時，光區跟隨玩家選取的畫中位置。
- 凝神模式中整卷灰白；光區恢復原畫淡彩與細節，周圍仍為灰白並稍微暗淡；沒有硬邊圓框、發光人物或自動吸附線索。
- 開啟閱讀、證詞、線索簿或選單時保留玩家所選模式；閱讀與問訊時暫停移動光區，收起後繼續。完成後展現全彩；重玩、換卷預設凝神。
- 觀察本身不錄入線索，也不改變人物及物件；掌櫃恢復一般問訊並提供書箱證詞。

## 實作

`ScrollScene` 的光區以視窗比例定位，隨視窗尺寸維持位置；半徑隨視窗尺寸縮放。遮罩在畫卷座標變換外，始終覆蓋網站視窗，使用 CSS 漸層與 backdrop-filter；沒有新增影片、SVG 或美術切換圖層。遮罩不攔截點擊。凝神模式使用灰白遮罩，並在玩家位置開出柔邊彩色區域；彩色模式移除遮罩，整幅畫卷恢復原畫淡彩。介面紙箋與圖示保持原本配色。
