# 共用章節轉場

使用者反映章節之間的流暢度及動畫仍不理想。源碼檢視發現，下方導航是直接改變 hash 或跳到獨立 HTML；沒有共用退場／入場流程。

## 實作

- `src/page-motion.js` 與 `src/page-motion.css` 同時供 React 首頁及康衢獨立文件使用；後者由章節組裝器內嵌。
- 同一絹色遮幕：180ms 覆蓋舊頁，切換至新封面後 300ms 揭開。固定畫面，不額外平移整幅原畫。
- 跨文件抵達時，由 CSS 絹色暫幕銜接至 runtime 遮幕，避免原畫在脚本解析前突然顯示。
- 導航連按由 busy guard 阻擋；修飾鍵、新分頁及外部來源連結保留原操作。
- 畫面內返回封面採用同一轉場；康衢保留原生文件內的返回流程及收藏。
- 系統減少動態效果時不播放淡轉；前進／後退及 bfcache 恢復會解除遮幕。
- 遮幕等待兩個畫面更新幀及封面中未完成的圖片，圖片等待上限 700ms；不等待整幅高解析原畫全部就緒。

## 限制

完成源碼檢視與產物建置，未執行瀏覽器互動或逐幀視覺檢視。實際跨文件讀取時間、字體與原畫載入速度受本機環境影響，480ms 是動畫時長，不是整段跳轉耗時保證。

## 第二輪：載入及鏡頭銜接修正

使用者仍觀察到停頓或畫面跳出。源碼追查發現：

1. 原有揭幕只查 `.introduction img`；真正的原畫及局部圖在封面以外，未被等待。
2. 康衢預覽沿用初始 `scale:.32`，高清載入後才切換至封面初始鏡頭，造成比例及位置變動。

已改為等待原畫背景、眼前局部圖解碼及兩幀版面更新，再揭幕。等待上限八秒讓載入失敗介面仍可顯示；它不是刻意的動畫停留。康衢在預覽出現前已定位鏡頭，高清就緒後只以 220ms 淡入提升清晰度，不重置位置。下方導航另預載歷史章節封面原畫，減少再次切換的冷載入。

本輪仍只完成源碼追查及產物建置，未以瀏覽器重現或確認所有停頓已消失。

## 第三輪：確認為章節封面切換

使用者明確回覆跳出發生在「切換到另一章封面時」。本輪修改：

- ScrollScene 提供 `data-assets-ready`，包含原畫及 requireTiles 的局部圖就緒狀態，轉場改用此明確訊號。
- 已存在的封面不再因八秒計時到期而提早揭開；載入失敗時仍揭開錯誤及重試介面。
- 共用轉場關閉原畫的既有載入淡入，避免兩套淡入重疊。
- 遮幕動畫用 fill:both 保持合成畫面，完成後才提交最終 opacity 及取消動畫，避免在開始／結束邊界先暴露下一頁。
- 康衢封面持續顯示固定预覽；高清提升清晰度留待離開封面後，不在封面顯示途中更換背景。

只完成源碼檢視與建置；未聲稱已在瀏覽器重現並消除問題。
