## 5. 重複收藏與點擊優先

1. 同實例的紙、筆或多個杯子可以分別設小熱區，但共用實例ID；同一類全部實例共用類別ID。
2. 任一實例首次被收下，保存 `category → instanceId + partIndex + sourceTile + localCoordinate`；見聞冊回看實際點中的首次位置。
3. 第二次點同類另一處：人物仍有自己的短回應，通知「這裡也有〔類別〕，已記在冊中」，數量保持不變；首次位置不覆寫。
4. 物件精確圈優先於人物擴充範圍；主線考生與身前箱子分開。找人不自動收箱，收箱不自動完成尋人。
5. 太小或互相重疊時先提示放大，不把整桌或整群設成大熱區。人物頭部錨點不代表最終只允許點頭部。
6. 主線、比較觀察、問訊次數、收藏及鏡頭分開保存；自由探索提前點看榜者／抄寫者不能跳過正式比較。

## 6. 主線串接提案

`入畫尋人 → 同行考生確認 → 玩家按看看榜前 → 看榜者＋抄寫者各點一次 → 一句比較解讀 → 玩家按回到橋邊 → 相逢 → 自由探索`

比較句：「同一張榜前，有人讀消息，也有人把消息記下來。」順序不限；重點同一位不增加種類。自由探索與收藏不要求集齊。提示由頭部樣貌開始；衣著提示需改為與實際灰青衣人物相符，不沿用未核對的顏色或「書箱」說法。

書童的場景落點與會合演繹尚未確定，不能在圖中隨意認定一位小孩就是書童，也不新增生成的人物。先用玩家委託的虛構按語交代會合，具體收尾定位在後續代表畫面討論。
