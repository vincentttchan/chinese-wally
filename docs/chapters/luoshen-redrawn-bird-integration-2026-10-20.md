# 重繪鳥形整合到洛神後的原畫觀察

使用者確認重繪方向後，要求整合至找到洛神後的原畫觀察，保留原畫對照及重播，避免與衣帶同時播放。

## 現行流程

1. 找到初見洛神 L1，讀人物短對白，按「近看原畫」。先觀察原畫中的雙鳥。
2. 點飛鳥：鳥形收藏先依原有規則記錄、去重與完成回饋；鏡頭及收藏回饋完成後，轉入重繪鳥形振翅。
3. 重繪鳥形直接融合在原畫中兩隻鳥的位置，不顯示獨立紙頁；6.2 秒演繹結束後保留畫中靜止重繪鳥形，可「再看一次」、「返回原畫」或「再看龍形」。
4. 返回原畫時仍停留在飛鳥觀察，不增加尋人進度；接續龍形後進入原有圖文對讀，也可「重看鳥形演繹」。
5. 播放及返回原畫的短暫淡出期間，原畫人物、工具和見聞冊操作停用；播完即恢復拖曳、縮放、收藏與工具操作，靜止鳥形隨畫卷保持對齊。Escape 淡出返回原畫。
6. 調整視窗尺寸會停止播放；減少動態時保留靜止鳥形；載入失敗退回原畫並可重試。

## 與衣帶的互斥

- 沿用單一 `useLuoshenAnimationPlayback`，唯一種類為 bird 或 ribbon，不另建播放器。
- 返回原畫與切換種類均會卸載前一動畫並取消 RAF／圖片回呼；共享控制器另以 ticket 阻擋過期完成回呼。
- 衣帶收藏、回原畫及返回見聞冊的流程保留；從飛鳥原畫切換衣帶，再關閉衣帶後可回到飛鳥觀察。
