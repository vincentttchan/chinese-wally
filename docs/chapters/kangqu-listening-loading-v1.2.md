# 康衢駢慶展卷載入調整

2026-10-13。使用者回報展卷速度慢；本次核對源碼與資產，沒有執行瀏覽器時間量測或測試。

## 改動

- 原先開場兩幕按鈕也等待高清原畫 ready。現行本地章節可先閱讀、推進前兩幕，引言最後的「入畫尋人」才等待清晰原畫載入與解碼。
- 背景先使用既有全景 JPEG，高清載入後收起預覽；尋人與細節點擊依然使用高清原畫。
- 原生 4500×2843 PNG 保留，新增無損 WebP 作運行素材，解碼後 RGB 像素雜湊相同。檔案由 15,450,097 bytes 降為 10,300,464 bytes，約減少 33.3%。原畫尺寸、互動座標及畫作邊界不變。
- WebP 載入失敗時改用原 PNG，再失敗才顯示原有重試介面。
- 小地圖改用既有全景 JPEG，沿用原畫座標與比例；不為縮小地圖另讀完整高清素材。
- 原畫設為 async decoding，在其解碼完成後開放入畫。通知主應用的 ready 包裝亦同步更新，組裝時確認函式字串存在，避免更動函式後遺失載入訊號。

## 資產記錄

`output/art-direction/wanshou-third-scroll/v1.2/art/native-segment-lossless.webp`、`encoding-record.json` 保留檔案大小、尺寸、RGB 像素雜湊與編碼方式。PNG 原檔沒有重繪、裁切、放大或覆寫。

這些是檔案大小及載入流程改善，不能據此聲稱實際速度提高了 33% 或已量得幾秒。首次本地檔案读取、圖像解碼、字體及瀏覽器狀態仍會影響實際時間；需要使用者重新開啟後確認體感或提供載入錄屏。
