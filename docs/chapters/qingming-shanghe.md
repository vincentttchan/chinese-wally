**商業種類的初步建議：**酒樓、香鋪、醫藥鋪、客店、紙馬鋪各提供不同角度；小食攤作飲食規模比較的條件候選。城郊運輸、船運、虹橋交易串連店舖探索。這不是已確認的九關順序，也不等於每列各找一人。

**共同解讀範圍：**由畫中與史料看商業多樣性、城鄉及區域聯繫、城市服務需求；城市化的增長速度與人口比例需另有跨時資料，不能由這幅畫單獨推出。夜市、坊市制度變化、海外貿易等可作後續文獻延伸，尚未選入必經觀察。

## 3. 引言與入畫

短引言、樣貌提示、入畫轉場沿用基準。暫定玩家問題：「這座城市裡，人們怎樣運貨、做買賣和過日子？」引言步數、初始鏡頭及樣貌圖待選主線人物後定。

## 4. 主線：找人 → 觀察 → 下一段線索

尋人 → 人物短對白 → 初看原畫 → 史料短句與必要註解 → 再看原畫 → 一句解讀 → 下一段線索。

- 史料短句為必經，較長白話、歷史背景及來源在見聞冊選讀。
- 讀到史料之後，要有一次回到原畫的操作，不能只按「讀完」。
- 不預先洩露店舖位置；樣貌、動作、地標按提示階梯逐步開放。
- 目標 ID、樣貌特徵、對白及主線數量均待選人；不因已找到店招便推定旁人是掌櫃或醫生。
- 比較及探索不固定變成選擇題；不以古文背誦作過關條件。

### 引路修訂：目的地須可判斷

使用者指出只有活動類型的短句不足以承接目的地，並接受以下修訂原則：**引路對白負責讓玩家找到場面，樣貌卡負責讓玩家在場面中找到人物。** 前表的泛泛引路句已被本節取代。

- 對白提供一個原畫可見地標或空間關係，不只說「去吃喝」「找住處」。
- 初始樣貌卡保持頭部範圍；引路可交代店面及招牌，但不圈出人物、不直接移鏡到答案。
- 第一段拆為紙馬鋪附近 → 虹橋觀察 → 入城找酒樓，不用一句話跨過多個地標。
- 虹橋觀察完成後，後續引路以短題箋承接；挑籃人物不跟隨鏡頭或移動到橋邊。
- 「前頭」「街對面」「沿街」等措辭須依原畫位置與最終鏡頭核對；使用者接受的是引導方向，尚不把所有空間描述視為已查證。

| 接力節點 | 修訂短句草案 | 目的地依據／待確認 |
|---|---|---|
| 紙馬鋪附近挑籃人 → 虹橋 | 「沿河往城裏走，先看看那座大木橋。」 | 以河道與大木橋作地標；保持全卷自右向左探索 |

| 酒樓 → 客店 | 「往街對面看看，住宿的招牌就在那邊。」 | 客店與酒樓同在城內街市，街對面關係按審閱局部及最終視角再核對 |
