# 《在人群中聽樂》版面修訂 v0.5

> 本版只修訂版面，仍混用效果稿按鈕及閱讀樣式。現行介面已由 [v0.6 元宵標準統一](kangqu-listening-interface-v0.6.md)取代。

2026-10-12。使用者指出章節版面與網站及其他章節不同。

## 原因及修訂

v0.4 把效果稿直接打包到主應用路由，只完成入口及素材接入。內頁仍用效果稿的頁首、左畫右欄、畫下工具列及頁尾。這是接入時沒有完成介面整合；使用者只確認過 0.2.3 見聞冊美術與並排方向，沒有確認整章都沿用雙欄閱讀頁。

本輪以 `LanternGame.tsx`、網站引言及 HUD 源碼為參照，修改本章自己的文件：

- 原畫場景佔滿視窗，移除常駐側欄與場景外頁首／頁尾。
- 引言讀入 `src/styles.css` 的既有引言規則；採用品牌、直排章節名、三幕短引言及入畫入口。
- 讀入 `src/lantern.css`、`src/lantern-search-hud.css` 的既有規則；角落尋人卡沿用網站紙框，放樣貌、當前目標及觀察進度。
- 凝神、全螢幕及更多在右上；冊子、縮放及尋人提示在底部。
- 尋人時收起提示；由玩家按尋人卡或提示按鈕打開。找到後、原畫觀察及畫中收尾出現小題箋。
- 原畫來源、完整構圖及區域入口收入「更多」。
- 見聞冊才開啟並排讀冊。四幅透明收藏插圖、兩欄圖樣及總覽／詳情分頁沿用使用者已確認方向；窄視窗改成上方原畫、下方冊頁。

- v0.4 打包前舊頁另存 `output/art-direction/wanshou-third-scroll/v0.4/application-before-layout.html`，只作歷程。

## 實際完成及限制

完成源碼對照、版面及狀態修改、文件組裝及素材打包。202 位人物、44 處收藏實例、三輪觀察及既有坐標修訂沿用 0.3.2；原始畫作檔案沒有編輯。

本輪未執行測試、應用建置、伺服器、瀏覽器／DOM／遊戲或裝置操作，沒有新的實際效果截圖；不能將本次版面標作視覺驗收通過。此前 275 項纯坐標檢查不作本輪版面結果。題箋與人物、手機冊頁、字體及按鈕的實際顯示仍待檢視。

此版為針對使用者意見的源碼修訂，未獲使用者確認定稿。
