# 髮型簡明圖解 v0.26

2026-10-21。使用者確認以簡單解說頁取代原畫重疊摹繪；此版本取代 v0.25 的展示方式。

## 互動

玩家仍須先點原畫中斜首女子的髮髻，才開啟共用 ChapterDialog 紙張圖解。完整髮型摹繪為主圖，可直接點高髻、髻上簪花、金色髮飾，也可用下方文字按鈕選擇；每次只呈現一項短解說，選中部件微微提亮。原畫局部與摹繪在同一圖區切換。頁面註明摹繪性質，保留資料依據連結。

「回到畫中」與關閉均保留原取景，再接續人物對話；亦可從「再看髮型圖解」重新開啟。原畫上不再疊放髮型摹繪或其部件標注。沿用既有透明髮型素材及共用紙張、按鈕、焦點管理。
