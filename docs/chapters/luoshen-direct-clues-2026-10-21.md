# 單一畫卷與全章直接點畫線索

2026-10-21，依使用者的重疊截圖及移除「靠近看」要求修正。

## 背景重疊

`ScrollScene` 原本在畫卷後方以整卷圖作 cover 背景。雲車原畫觀察在窄螢幕需要縮小並讓出題箋空間，畫卷上方會出現留白；背景便露出另一比例的題字／鈐印。原有 CSS 僅在少數情境隱藏該背景，切換場景會再次露出。

新增預設為 true 的 `showBackdrop` 選項；洛神章節明確設定 false，所有階段、題箋收合、古籍、見聞冊、縮放與轉向均保留單一可操作畫卷及既有素色絹底。其他章節沿用原預設，宮中鬧元宵的畫面沒有改變。背景機制離線對照保存在 `output/luoshen-direct-clues-2026-10-21/background-comparison.png`，重現同一雲車取景和背景填入邏輯，並非實際瀏覽器截圖，沒有模擬題箋或工具列。

## 統一線索操作

主線與畫中收尾的「靠近看」選項全部移除。保留找到人物後的短對白與「近看原畫」入口；進入線索後自動取景，再直接點原畫對象。已有飛鳥、龍形、洛神、兩岸與雲車動畫，以及髮式圖樣回饋維持原有方式。

其餘七個線索（曹植展袖、同行者收袖、榻前神女、牽引龍形、舟上曹植、下層舟人、操船長桿）改為點中後先停留：短暫柔和聚焦、題箋顯示一項畫中發現，只有「下一處」或最後的「圖文對讀」一個下一步。重點是確認點中並讀懂細節，不為每處新增虛構動作。減少動態時不播放聚焦效果，短句與進度照常。收尾原有「點中後停留、單一繼續」保留，並自動取景與提供同樣點選回饋。

所有普通線索及收尾共用小題箋與取景計算，手機直向畫面在題箋下方、寬畫面在題箋左方；畫卷留邊以素色絹底填滿。每個普通線索的發現以 `detailSeen` 保存，重新載入仍須由玩家按下一步，舊 version 2 存檔相容，過時或重複的下一步不跳段。打開見聞冊再合冊會還原原有視角，包括縮小取景的垂直留邊。
