# 街上的運輸：由人物動作引出故事

日期：2026-10-19。使用者確認以街道作第一段自由故事示範：點人物、看不尋常細節、追問、點原畫證據，才拼出生活片段。本輪已修改正式遊戲，其他四個自由故事沒有改寫。

## 原畫與實作

原畫仍是張擇端北宋本，沿用 `story-street.jpg` 及既有全卷分塊。檢視可見兩頂轎子及兩旁扶杆／扛杆人物，右方有負載牲口及載物獨輪車；不指定轎內人物、貨物種類或出發目的。

- 左轎：`extra-object-city-039` [4150,1091,4432,1398]，對應人物 `city-148/150/151`。
- 右轎：`extra-object-city-040` [4695,1090,4894,1398]，對應人物 `city-153/155/156`。
- 車：`extra-object-city-045` [5437,950,5724,1166]。近看原畫後，新增車輪範圍 `detail-transport-wheel` [5555,1077,5625,1155]；小熱區在人物身體外可直接命中，不修改既有人物臉部優先規則。
- 負載：保留負載清楚的 `extra-object-city-042/044`，沒有把模糊鞍具一律算作貨物。

先點人物，就沿杆找同頂轎；先點轎身，就反向找相連人物。`storyStepAt` 依真實先點位置產生當前題箋與目標。肩上有杆者使用「肩上」，身旁扶杆者用「身旁」，避免同一句硬套到不同姿勢。另一頂轎可有自己的回應，但不代替當前對應。

完成聯繫後，車與牲口可自由選先後；點第一類後才出另一類的追問。原畫光區先出，文字稍後顯示；停留不推進。最後合看轎、車與負載，玩家主動收下故事。沿用元宵絲箋與按鈕；本段題箋移到上方，取代重複的任務卡，讓下方的長杆、人物、轎身保持可見。

## 保存與範圍

## 實際檢視

正式頁面 `http://127.0.0.1:5179/#qingming-shanghe`，內建瀏覽器，897 × 853。舊分頁初次讀取只有空頁，重新載入後恢復正式清明章節；本輪先啟動伺服器，沒有另開錯誤頁或使用其他瀏覽器繞過限制。

實際操作：

1. 從「給我一個去處」抵達街道，先保留原畫；點 `city-151` 後聚焦，稍後出現長杆追問。
2. 點右轎仍留在問題，並有該轎的短回應；點左轎才進入比較，人物與轎身的對應正確。
3. 初次點輪子附近命中扶車人物，故近看原畫並加入獨立輪子小熱區。修正後直接點可見車輪，出現「旁邊不用車輪的負載，又落在哪裏？」；不顯示車與牲口的完成清單。
4. 比較中重新載入，車輪已看仍保存。發現原本鏡頭回到別區，修正後重載已回到街道，繼續問剩下的負載。
5. 點左端負載牲口後才合看三種運法，按「收下這則見聞」完成；冊中顯示故事 1／5、收藏仍 2／6，可回顧四處已看證據。
6. 最終改動後 `npm run build` 退出碼 0，TypeScript 與 Vite 完成，129 模組，JS 約 948.76 kB；仍有超過 500 kB 的分塊提醒，本輪沒有擴大修改共用載入架構。
