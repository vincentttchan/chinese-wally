# 同看兩人：同步原位演繹

使用者要求「同看兩人」時兩人的動畫同時出現。點該唯一下一步後先取景原畫中的兩人，再一起播放既有神女與曹植摹繪動畫，約 3.4 秒後一起還原。單獨觀察兩人的前段仍各自播放。

雙人模式仍只有一個 farewell 播放擁有者；兩個局部渲染器共用時鐘，必須兩份素材都準備好才開始。同一畫格取得相同時間，避免載入速度不同而先後起動。任一載入失敗就一起撤下，原畫與「繼續故事」可用；原位點人物可重試。

播完可點原畫任一主角重播兩人。播放中點任一主角或 Escape 一起返回原畫，轉向取消後重新取景。翻開古籍會停止兩段，合卷回原畫而不自動重播。減少動態不載入動畫素材。刷新／恢復已完成的兩人回看不自動播放。沒有新增文字播放按鈕或比較分頁，只保留小題箋及「繼續故事」；播放中該下一步暫停用。

素材沿用神女 v1、曹植完整母圖 v2／補底 v3，沒有新增生成美術。原畫、素材來源及衍生使用條件沿用 `docs/art/luoshen/farewell-animation-v1-2026-10-21.json` 與 `docs/art/luoshen/cao-animation-v2-2026-10-21.json`。兩人可在這個指定段落同步；飛鳥、初見洛神、龍形仍不與這個播放擁有者並播。

`output/luoshen-pair-animation-2026-10-21/paired-in-painting.gif` 是同一素材與渲染函式的離線預演，非瀏覽器錄影。已檢視兩人同框的峰值合成；實際瀏覽器 CSS、手機觀感／效能與學生試玩仍待確認。未重試先前遭安全政策拒絕的瀏覽器存取。

最終相關 96 項模擬／純函式檢查及 TypeScript 通過。新增檢查涵蓋兩種素材載入順序的共用時鐘、桌面／手機同時顯示與還原、原畫觸控重播、Escape 返回、古籍開合、任一載入失敗一起撤下、轉向取消與減少動態；原有六次尋找、收尾、收藏／見聞冊及排版回歸亦通過。結果見同目錄 `test-results-final.txt` 與 `typecheck.txt`，不等同實際瀏覽器驗收。
