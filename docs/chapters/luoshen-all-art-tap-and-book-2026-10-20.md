# 飛鳥／洛神點畫互動及《洛神賦》書頁

2026-10-20。依使用者已認可的龍形點畫方式擴展飛鳥和初見洛神；圖文對讀依使用者指定，參照《清明上河圖》的《東京夢華錄》古籍道具及書頁。

## 玩家看到的改動

- 飛鳥、龍形、洛神都直接點原畫中的對象播放；完成後卸下演繹圖層及補底，回到原畫，再點即可重播。飛鳥不再長留重繪靜幀，會先淡出回到原畫。
- 飛鳥和洛神題箋移除播放／重播文字按鈕，只保留短句、播放中原畫中止及下一步／退出。拖曳與雙指操作沿用原畫場景，不另加攔截手勢的透明浮層；重播不重設玩家鏡頭。
- 點初見洛神整個身姿也能播放；初見衣帶收藏先完成入冊回饋，再啟動動畫。同類仍只記一次。其他位置的衣帶只提供收藏回應，沒有把別處人物換成初見洛神，也不再自動跳回初見播放。
- 主線、收藏、見聞冊、原畫對照及三段動畫互斥保留。減少動態時保留原畫，仍可繼續。

## 古籍取代長題箋中的圖文解讀

每次主線觀察完成後，原畫旁出現《洛神賦》薄冊。點書打開相應短句，原文由右至左直排，點原文顯示頁邊短批注並留下讀記；合卷回到相應原畫細節。只保留兩處原畫比較與故事繼續；原來的長解說、圖文小記與動畫回看文字列不再堆在主線題箋。

共六段對應書頁：

| 原畫觀察 | 書中節錄 |
|---|---|
| 岸上初見、衣袖 | 余情悅其淑美兮，心震蕩而不怡。 |
| 飛鳥與龍形 | 翩若驚鴻，婉若遊龍。 |
| 身影重現 | 進止難期，若往若還。 |
| 兩岸離別 | 恨人神之道殊。 |
| 雲車離去 | 載雲車之容裔。 |
| 乘舟尋望 | 御輕舟而上溯。 |

短句核對國立故宮博物院書法釋文；標點由專案整理，批注是現代閱讀提示。第一段的心情、離別的意義均明示來自賦文，不憑原畫動作推定；「輕舟」不硬套為畫中樓船的精確船型。書是遊戲閱讀道具，不是假稱原畫中已有書冊或復原某一古籍版本。

`LuoshenPoemBook` 直接使用 `QingmingBookLeaf`；只新增可選的書名／作者／批注／返回文字與原文分句參數，未傳參數時《東京夢華錄》的書名、孟元老、閱讀規則及界面文字不變。沿用展開頁素材；封面另以同一參考圖將書名改成《洛神賦》，原檔保留。封面、提示與來源見 `public/art/luoshen/BOOK-CREDITS.md`。

手機封面安排在右上，避開下方小題箋及初見神女的身姿；短橫屏書頁可整頁捲動，避免縮小原文字級。這些是實作安排，尚未作實際瀏覽器排版驗收。
