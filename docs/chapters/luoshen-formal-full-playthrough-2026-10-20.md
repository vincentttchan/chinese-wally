依使用者要求重走正式《洛水之間》的六次尋找、畫中收尾、點畫動畫、古籍開合與收藏／見聞冊。檢查對象為 `#luoshen` 使用的正式 `LuoshenGame` 元件，不使用試玩入口的預置階段，也不改動使用者瀏覽器存檔。

## 新發現及修正

手機第三段古籍中，選讀「若往若還」合卷，鏡頭雖回初見洛神，面孔卻落在左上書冊下面。另一句「進止難期」所對照的坐榻前神女，其臉也過於貼近書冊邊緣。

原因是取景以人物衣飾的大矩形中心計算，面孔偏在矩形左邊。390×844 的初見洛神臉中心約在 x=67、y=155，而書冊占 x=16..80、y=78..174。坐榻前神女的臉中心約 x=101，亦沒有足夠臉部留白。

在 `frameReading` 保留現有比例及縱向取景，只在窄屏有需要時，按已核對的原畫面孔位置把對照主體向右留位。上述兩處臉中心均至少到 x=112；書冊位置不變，保留飛鳥原有避讓。桌面取景不變。

新增完整觸控命中旅程及面孔避讓檢查先重現失敗，修正後兩輪通關和相關回歸通過。重現輸出保留在 `book-overlap-reproduction.txt`；修正前後鏡頭另存。

| 古籍對讀 | 六段共九句原文分別開卷、選句、顯示今人批注、合卷；主線階段與收藏不被開合改動；合卷後可再點飛鳥播放 |
| 合卷取景 | 對應原畫仍可操作；補上面孔避開左上書冊的檢查，修正第三段兩處面孔留白 |
| 收藏 | 在尋人途中點得華蓋、龍形、鳥形、衣帶，再於樓船段點得舟船，最終 5／5；既有回歸另外檢查全部 30 處與同類去重、連續收藏回饋 |
| 見聞冊 | 每段解讀都開合一次，保存進度並還原鏡頭；完成後五類詳情 → 首次原畫對照 → 返回原項目 |
| 故事回看 | 相遇、流連、離別、追懷均可開啟及看原畫，返回保留篇章 |
| 畫中收尾 | 岸邊坐候 → 車輪 → 車中回望，三次觀察後完成；自由探索與見聞冊仍可用 |

1000×800、390×844 各完成一輪新增旅程：透過 Scene 的滑鼠拖曳處理器移卷，再以 touch pointer 點擊已在畫面內的原畫座標；尋人使用核對過的面孔位置，觀察／收藏使用登記的畫中位置。沒有用程式直接 dispatch 主線完成事件。

這是輸入與場景邏輯檢查。happy-dom 不計算真實 CSS 遮擋、多指手感或畫面更新率，不能視為真人在手機上完整試玩。

另重跑原有兩輪新進度與相關檢查，共 **72 項通過、0 失敗**；TypeScript `tsc --noEmit` 通過。沒有宣稱全專案測試通過，也沒有調整《宮中鬧元宵》。測試環境補上目前共用章節導覽所讀取的 `document.fonts.ready`；此項只屬測試替身，沒有改動導覽實作。
