# 虹橋：先察覺，再追問

日期：2026-10-15。使用者確認以玩家先察覺動作、之後浮現追問的方式推進。這次只修改正式虹橋引導，五個自由故事的文案、觀察順序與城市聯繫保留；沒有新增效果稿入口。

## 改動

- 引言縮成「在橋邊停一停。」；入畫只邀請點看人物，移除開場直接指出前傾與橋下船隻的說明。起始正常彩色，沒有下方題箋。
- 點橋邊人物立即顯示柔和光區。約 1.6 秒後才顯示「這幾個人，正在留意甚麼？」；短暫留白時也隱藏上方任務卡，讓原畫先承擔注意力。
- 玩家點原畫大船後，轉到船上光區，約 1.2 秒後才提示伸出的手臂；點相應人物後合看橋船，約 1 秒後顯示小故事按語。
- 留白僅屬顯示狀態，不寫入完成進度。原畫點擊維持開放；提前點中當前目標也可前進。離開當前步驟或開啟面板時清除尚未執行的顯示計時，重看引導使用新的顯示識別。
- 按語保留是否互相呼應的疑問；玩家按「看過了」後才以「河上的往來，又怎樣連着城裏的生活？」接出《東京夢華錄》。書冊仍需主動翻開，原文批注及回畫對讀不變。
- 正確點中引導目標時清除先前的誤點提示，避免舊提示留到下一幕。沿用原觀察 ID、步驟索引、存檔與去重，不增加存檔遷移。

程式範圍：`src/game/qingmingStories.ts`、`src/components/QingmingGame.tsx`、`src/qingming.css`。正式設計的引言、共用規則及虹橋表已同步於 `qingming-free-roam-design-v1.0.md`。沿用元宵絲箋、圖示、字體及現有手繪書冊；沒有新生成美術。

## 實際檢視

本輪使用內建瀏覽器，正式 URL 為 `http://127.0.0.1:5179/#qingming-shanghe`，當前畫面 897 × 853。本機 Vite 原先停止，啟動後曾因舊連線錯誤頁被網址安全檢查拒絕；使用者手動開啟正常遊戲後成功取得頁面，沒有以其他瀏覽器或其他操作表面繞過限制。

實際操作「重看虹橋引導 · 保留故事與收藏」後，確認：

1. 入畫沒有下方觀察題箋，起始原色；點橋邊人物後先有聚焦，當下可操作的原畫按鈕仍存在，沒有追問文字。
2. 稍後浮現單句追問；停留後仍在等玩家點船，沒有自動完成。
3. 點大船轉到船上；重複點船身留下提示，沒有跳過人物；點船左伸臂人物後才合看橋船，稍後出小故事按語。
4. 按「看過了」才出新城市疑問及薄冊；主動翻書、點必要短句、合卷後，仍須重新點大船完成對照。
5. 收下虹橋後成功回到自由漫遊；既有收藏維持 2／6，沒有重複增加。頁面 error／warn 紀錄讀取結果為空。

最終改動後 `npm run build` 退出碼 0：TypeScript 與 Vite 打包完成，97 模組，JS 約 824.12 kB；既有超過 500 kB 的打包提醒仍在。本輪沒有新增或執行測試套件，沒有檢視手機版、全部舊存檔組合或重走五個自由故事。沒有學生試玩，不能由短延遲推定玩家已察覺動作或產生好奇；這仍需使用者體驗及之後的實際試玩判斷。
