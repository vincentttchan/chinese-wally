# 《清明上河圖》主線流程草案 v0.2

日期：2026-10-13。依據：[章節設計](qingming-shanghe.md)、[人物裁圖與座標](qingming-character-candidates-2026-10-13.md)。

已確認：五類店舖及五人組合、人物接力引路、原畫與《東京夢華錄》短句必經、長解說見聞冊選讀、引路須有可見地標。以下逐站問題、對白、操作及收尾為本次細化草案，供討論；不是已製作的遊戲。

## 共用節奏

樣貌尋人 → 短對白 → 玩家選「近看」 → 一次原畫操作 → 短史料及必要詞註 → 一次回到原畫的操作 → 一句理解 → 玩家選「問下一處」 → 引路對白與下一人的頭部卡。

每次只呈現一個問題、一個主要操作；讀完文字不直接判作完成。小字招牌由玩家主動近看，保留原畫與題箋並置；不以抄寫、背誦或多選題作過關條件。頭部提示、對話框與題箋沿用《宮中鬧元宵》現行介面。

原畫觀察、古籍記載、遊戲虛構分別標示。所選人物附近的店舖可核對；人物職業及是否彼此相識未由原畫證實。下列人物對白全屬遊戲虛構，不讓旁邊人物自稱店主、名醫或實有店主姓名。

## 1. 紙馬鋪附近：節令需求與專門商品

- 尋人：紙馬鋪 B，挑着兩只籃子的行人。初始提示用頭部原裁圖；需要時才補挑籃姿態。
- 找到對白：「想看這裏的生意？先看看那塊店招。」
- 初看問題：「這間鋪子賣的是甚麼？」玩家點店招，題箋提供可辨認字的輔讀，不要求學生自行讀出全部古字。
- 史料：[卷七〈清明節〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷七)：「紙馬鋪皆於當街用紙袞疊成樓閣之狀。」主線白話：書中記載紙馬鋪在街邊展示紙製樓閣；「紙袞」的具體詞註待指定校注本核對。
- 回畫操作：「再看看這家店怎樣展示商品。」點店前可見陳列；不把每個形狀判定為書中所說的紙樓閣。
- 一句理解：「祭祀與節令用品，也能形成專門的生意。」
- 引路：「沿河往城裏看，先找那座大木橋。」
- 範圍：B 是附近行人，不把他的籃子與紙馬貨物連成已知事實。

## 2. 虹橋：船運與城市供應

- 此段不另找第六人。紙馬鋪人物留在原處；玩家依線索自行拖曳找到橋。
- 以橋的物件熱區確認抵達，不圈出船工或下一人物。玩家選「看看橋下」才近看。
- 初看問題：「橋下的船，正怎樣通過這裡？」玩家點船、桅杆或船工動作的分步焦點；具體可點細節須補做橋段高清裁圖定位。
- 史料：[卷一〈河道〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷一)：「運東南之糧，凡東南方物，自此入京城，公私仰給焉。」方物＝各地物產；仰給＝依靠供應。
- 回畫操作：「河運與岸上的生活怎樣相連？」先點船，再點一處岸上商業活動，分步觀看同一局部的水陸關係。
- 一句理解：「河運把外地物產帶入京城，是城市供應的重要聯繫。」
- 接力題箋：「再往畫卷左邊找城門，入城後留意門面結彩的酒樓。」文字可分兩步，玩家找到城門後才顯示後半句；下一人頭部卡保持可用。城門確認用地標熱區，不增加人物任務。
- 範圍：過橋動作是原畫場面；城市供應是史料提供的理解。畫中這艘船的具體貨物、商運或官運未確定，不稱它是海外貿易船。

## 3. 酒樓：店面與飲食消費

- 尋人：酒樓 A，正店牌旁坐姿人物。
- 找到對白：「這家店的門面，你可看仔細了？」
- 初看問題：「店門前有哪些招徠客人的東西？」玩家先點招牌；初看不要求一次點遍全部裝飾。
- 史料：[卷二〈酒樓〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷二)：「凡京師酒店，門首皆縛彩樓歡門。」詞註：店門前搭起彩飾門架。
- 回畫操作：「在原畫找找彩飾門架。」點入口相應裝飾，再顯示一處原畫細節與詞註的對照。
- 一句理解：「招牌與彩飾門面，讓街上的人看見店舖、前來消費。」
- 引路：「看看街的另一邊，那塊『久住』招牌。」以明確店招替代尚未證實的角色職業；實際對街關係需在最終鏡頭核對。
- 見聞冊：正店與腳店、飲食服務、較小食店的比較選讀；不直接把正店等同現代星級酒店。

## 4. 客店：外來人口與住宿服務

- 尋人：客店 A，住宿招牌旁伸手人物。
- 找到對白：「那塊招牌，說的是住下來的生意。」
- 初看問題：「這塊招牌提供甚麼服務？」玩家點「久住王員外家」店招。
- 史料：[卷三〈大內前州橋東街巷〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷三)：「南方官員商賈兵級，皆於此安泊。」商賈＝商人；安泊＝住宿。
- 回畫操作：「比較客店與剛才酒樓的招牌。」玩家依次回看兩處原畫；酒樓供飲食與客店供住宿的短註在兩次點看後呈現，鏡頭由玩家控制進入。
- 一句理解：「往來京城的人需要住宿，客店是城市服務的一部分。」
- 引路：「沿街往左看，找高高立起的香鋪招牌。」原檔客店招牌與香鋪位置支持往左；最終鏡頭若只見局部，提供同樣方向的地標提示。
- 範圍：書中南方商賈是同類活動的背景，不判定眼前人物來自南方，也不稱伸手人物是王員外。

## 5. 香鋪：商品種類與專門店舖

- 尋人：香鋪 A，高帽長袍人物。
- 找到對白：「想知道賣甚麼，先看看店招。」
- 初看問題：「招牌上有哪些商品線索？」玩家點高立店招；部分字詞不清楚時依來源提供輔讀，標明釋讀。
- 史料：[卷二〈東角樓街巷〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷二)：「餘皆真珠、匹帛、香藥鋪席。」匹帛＝紡織品；短註說明書中列舉不同專門店舖。
- 回畫操作：「原畫這家店，對應書中哪一類生意？」玩家再次點招牌可辨認的香料商品字詞，以原畫文字完成對讀，不另加選擇題。具體字詞以最終招牌釋讀為準。
- 一句理解：「城市商業有不同種類，店舖可以專營某類商品。」
- 引路：「再沿街往左，找『趙太丞家』的招牌。」
- 見聞冊：香料用途與有史料支持的流通背景；不由店招推出某件商品的海外產地。

## 6. 醫藥鋪：專業服務與分工

- 尋人：醫藥鋪 A，趙太丞家店內坐姿人物。
- 找到對白：「這裏的招牌，還寫着治甚麼病。」
- 初看問題：「除了店名，還有哪些介紹？」玩家點一處藥品／治療宣傳文字。小字須近看，輔讀保留原畫對照。
- 史料：[卷三〈馬行街北諸醫鋪〉](https://zh.wikisource.org/zh-hant/東京夢華錄/卷三)：分別節錄「口齒咽喉藥」「醫小兒」「產科」。清楚標示三處節錄，依次顯示，不拼成連續原句。
- 回畫操作：「這家店怎樣介紹自己的本領？」回到同一宣傳文字，點看可支持治療／藥品類別的一處；不把書中三科強加到眼前店舖。
- 一句理解：「城市生意不只售賣物品，也提供有專門本領的服務。」
- 收尾對白：「一路看過來，各家都有自己的生意。」玩家選「回看這一路」才進入畫中收尾。

## 畫中收尾候選

沿用原畫、題箋與既有元件，分三個焦點，由玩家依次選回看：

1. 船與岸上活動：城市與外地供應相連。
2. 紙馬鋪、酒樓與香鋪：節令、飲食及不同商品需求形成多種生意。
3. 客店與醫藥鋪：人口往來及日常生活需要不同服務。

最後按語草案：「船運、店舖與各種服務，連成了汴京的城市生活。」選讀補充這些發現如何幫助理解北宋城市發展；不由單幅畫聲稱已證明人口增長幅度、全國城市化程度或每處真實地理位置。

完成後提供自由探索、回看見聞冊、再尋一次。主線與支線獨立，不要求收齊收藏；不增加已移除的「細看畫法」。
