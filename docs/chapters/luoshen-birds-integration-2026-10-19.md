# 雙鳥原位動畫：接縫精修與主線整合

日期：2026-10-19；取代同日早期獨立示範的翼根／補底限制。其餘動畫候選仍以[優先方案](luoshen-animation-plan-2026-10-19.md)為準。

## 現行版本

雙鳥演繹已加入 #luoshen 的第二次尋找：找到初見洛神 → 短對白 → 近看原畫 → 點飛鳥 → 收藏回饋完成、鏡頭停定 → 播放約 4.2 秒 → 原畫／重播 → 玩家按「再看龍形」→ 龍形觀察 → 圖文對讀 → 繼續下一次尋找。圖文對讀另有「重看雙鳥演繹」，返回後仍可繼續故事。

動畫不自行完成觀察或推進故事。中途「返回原畫」、Escape、尺寸改變會撤下演繹，仍可繼續；重播不重複收藏。減少動態直接保留原畫，素材／繪圖失敗可重試或繼續。

試玩入口：[由第二次尋找開始](http://127.0.0.1:5176/#luoshen-birds-playtest)。同一個 LuoshenGame 及同一段主線邏輯，僅起始於第二次尋找；試玩不寫入正式存檔。原有 #luoshen 進度及 schema 不變。

## 接縫修正

- 上一版的鳥身／上翼分層、翼根補片及生成絹底均退出現行播放；舊補底檔保留製作歷程，程式不再引用。
- 改為對原畫 detail-8 的 236×124 局部做連續像素變形，兩處翼根固定，翼尖小幅變化，背景和墨線是一張連續表面，無切開的翼根。未增加鳥種、姿勢、表情或飛行路徑。
- 變形於四周回到零；以雙線性取樣處理小數位置。播放起止回到原圖像素，停止／結束整層移除。
- 動畫 canvas 套用與原畫圖片相同的 --painting-grade；這修正了上一版未同步顯色所造成的色差。局部外圈柔化處理顯示縮放的細微取樣差。
- 鳥形、絹紋及顏色全取自原圖；沒有新生成素材，也不再載入 silk-plate-v1.png。演繹仍屬動作推定，並非原畫本來會動。
- 飛鳥觀察熱區改用 tile 8 原生座標 x1120–1330、y50–152，涵蓋兩鳥。滑鼠點原畫兩鳥及鍵盤左右鳥入口均觸發同段觀察，收藏首次位置仍按類別去重。
- 題箋已有演繹標示，播放時隱藏重複的底部標籤，避免壓住見聞冊；收起題箋時另顯示於底部操作之上。
