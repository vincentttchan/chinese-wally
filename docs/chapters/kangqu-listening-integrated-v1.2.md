## 4. 主線：尋人與必經觀察

| 次序／人物 ID | 觀察操作 | 解讀與下一段 |
|---|---|---|
| 1 seated-drum | 鼓 → 身旁持鈸者 | 亭內是一組合奏；尋持旗者。 |
| 2 red-front-east-05 | 所持黑旗 → 同列另一黑旗 | 重複旗形與隊列構成儀仗；尋彩衣人物。 |
| 3 watcher-pattern | 彩衣 → 左旁玉板彩牆 | 裝束與道具構成表演場景，暗八仙彩牆承載吉祥祝意；尋觀看者。 |
| 4 watcher-blue | 亭外觀者頭部／朝向 → 亭內樂隊 | 比較亭內演奏、亭外觀看，理解亭前街道成為表演空間。第二步移至樂隊，替換重點彩衣人物。 |

第四輪虛構對白：「亭外有人觀看，亭內有人演奏。」兩處觀察之間平順移鏡，手機可順序比較。完成後玩家主動進入最後探索。

提示階梯仍為樣貌 → 衣著／姿勢 → 地標／大致區域；玩家再要求才移鏡。具體頭部、身體與區域座標保留於 content-revisions.js。

## 5. 盤點與命中

現有登記 202 人物、47 件物件；原畫高清段落以外未有同等覆蓋。完整座標、三句虛構對白、來源局部與排除項保留於 v0.3.2/inventory.js、collection-revisions.js、diagnostic-revisions.js 及 v1.2/content-revisions.js。202 位人物的三句回應已由 dialogue-revisions.js 覆蓋，逐人文案與原畫依據保留於 dialogue/dialogue-evidence.json；本次完成逐段視讀與文案修訂，尚未實測對白排版。

- 精確臉部和精確物件命中優先。
- 小前景物件增加距離輪廓的容錯，按屏幕比例計算，最多 18 屏幕像素；不擴張成整亭或整個人物答案區。
- 原畫精確物件先判定；鄰近容錯只在未點中臉部時使用，以距離最近的物件優先。
- 原畫必經觀察設定至少 44 屏幕像素的目標起點；保留既有臉部排除。
- 題箋嘗試側旁、上／下與角落位置，避開待點細節，再減少其他頭部遮擋。空間不足時題箋可滾動；極小空位時暫收，右下「查看題箋」可再讀。玩家也可主動「暫收題箋」。
- 鍵盤人物按鈕使用盤點的人物名稱，物件按鈕使用收藏名稱。

以上為實作規則，手機誤點與題箋實際排版尚未操作驗證。

## 7. 最後探索

| 步驟 | 原畫與操作 | 學習進展 |
|---|---|---|
| 回看三處 | 樂隊與街道、儀仗與路線、彩牆與祝意，各點一次 | 從辨物轉為理解不同活動在街衢中的功能。 |
| 連起發現 | 退後看畫，判断「沿街安排的一場慶典」／「偶然聚集」 | 用隊列與彩牆支持組織性解讀；另一選項只提供證據提示，不扣分。 |
| 祝壽背景 | 回到表演與布景附近，讀一則短題箋 | 為誰祝壽、母子關係、事件年份。 |
| 駢慶解讀 | 回到儀仗附近，讀一則短題箋 | 雙慶：皇太后萬壽與同年首次南巡禮成；明示研究解讀，來源可展開。 |
| 演繹 | 主動點鼓手／持鈸者 | 原畫手部小幅演繹；完成恢復原畫並給短解說。 |
| 畫中按語 | 退後看街衢 | 兩個發現：沿街安排的祝壽場景；研究從儀仗讀出的雙慶。 |

完成出口只保留自由探索、回看冊子、再尋一次。回看三處／重播演繹收在可展開內容；自由探索提示仍提供回看入口。沒有恢復「細看畫法」。

## 8. 視覺與動畫

按鈕、字體、圖示、題箋、對白與冊頁沿用現行共用 CSS 與素材，章節只改內容、幾何、手部演繹與已確認兩欄。鏡頭 500ms，減少動態直接停定；手部演繹 4200ms，減少動態原位短展示 1200ms。

| 動畫 | 依據與分層 | 固定部分／結束 |
|---|---|---|
| ensemble-native-motion | 原畫 [880,2290,1085,2560] 內鈸／鼓手部兩片像素，羽化遮罩，小幅平移旋轉；所有已登記頭部挖空保護。 | 原畫底圖、臉、鼓與亭子固定；開頭與結尾位移歸零，移除覆層恢復原畫。 |

本版不在運行時讀取生成補底或生成整身姿態。歷史素材與提示詞留於 animation/generation-records.json 的 archivedGeneration。這是手勢示意，不能聲稱重建實際節奏、旋律或完整擊鈸動作。可重播、按略過／Escape 結束；載入失敗仍可繼續。
