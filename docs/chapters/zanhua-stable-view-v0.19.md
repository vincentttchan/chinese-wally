# 簪花仕女圖 v0.19：穩定閱讀取景

2026-10-21。使用者指出視野不斷轉動、不方便觀看。v0.18為避開遮擋而頻繁返回人物面孔，造成細節、人物、下一句提問之間反覆滑移及縮放；本輪改以保留目前原畫取景為優先。

## 改動

- 進入衣飾解說、點中細節、逐句回應、展開來源及接續線索時，均保留畫卷位置。換到下一個提問也先留在原位；玩家按「讓我看看」才定位至新細節。
- 動畫結束或略過後保留播放時的取景，取消自動返回人物面孔。
- 支線短對白直接在目前畫面出現，不再為每句話拉鏡。
- 本章需要定位時改用新增的`StudyCommand.transition='instant'`，取消600毫秒滑移／縮放過場。其他章節原有pan／crossfade行為維持。
- 解說對話紙張固定在原操作題箋的閱讀區。人物回應標出垂首女子、持花女子或執扇侍女等說話者，移除會指向畫外面孔的尾針；歷史資料仍標「畫外解說 · 史料」。扇面後的線索沿用上方紙張位置，避免又移回鄰人頭部。
- 原畫拖曳、縮放、凝神及人物動畫保留；手動選擇尋人、看細節、回望與見聞冊回看時仍可定位。

本輪取代v0.18「支線及每個回應先移鏡」的安排。v0.18截圖保留作歷程，不代表現行回應流程。
