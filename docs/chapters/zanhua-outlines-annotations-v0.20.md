# 簪花仕女圖 v0.20：點中回饋與衣飾標注

2026-10-21。回應使用者三項要求：對白位置不準、點中後缺乏明顯回饋，以及深入衣着與髮型。使用者參考圖的重點是金色輪廓與部件引線；未使用其第三方畫面或另建一套介面。

## 現行行為

- 撤回v0.19固定左上閱讀區的CSS：按目前可見的說話者嘴部定位，依現有共用紙張尺寸避開面孔、人物、收藏及觀察目標。說話者在畫外時顯示具名旁述，移除指向畫外的尾針。
- 共用排版器新增可選的`openSpaceCandidates`，本章開啟，讓紙張在人物旁空位不足時也能選擇畫面邊緣空位。其他章節預設不變。讀解說不移動畫卷；玩家選看另一處才直接定位，沿用v0.19穩定取景。
- 尋得三位主線人物後以原畫輪廓描金；點中觀察、衣飾或收藏時，目標範圍描金並顯示「已找到」。輪廓在當前段落保留，切換段落清除。輪廓僅初次淡入，不持續閃爍；減少動態偏好下不淡入。
- 觀察成功後顯示小型紙籤及引線。玩家可逐一點開小注，再返回原本人物對話，不另開大卡片或移鏡。部分微小飾物以局部圓形圈示，與衣飾範圍輪廓區分。
- 新增12項原畫標注：紅色裙襬、寬袖外衣、高束裙腰、寬袖紗衣、花紋披帛、曳地長裙、紅帶束髻、長柄扇、高髻、髻上簪花、金色髮飾、紹興連珠印。資料見`src/game/zanhuaAnnotations.ts`。
- 紗衣、裙腰與披帛分開解說，並有「還有哪些唐代穿搭？」可選延伸，呈現襦裙、胡服及男裝等不同形象。高髻小注說明館方的義髻解釋；不據複製圖強定髻名、花種或金色飾物材質。
- 人物對話保留「遊戲對白」，歷史解說及小注分別標明，各附資料連結。紹興印使用「原畫小注 · 流傳線索」。
- 本章關閉共用對白的局部Tab循環，讓鍵盤能進入框外的圖中標注；其他章節維持原預設。

## 限制

輪廓是既有原畫描邊／目標範圍，未重新精描每根髮絲。引線及紙張依可見畫面計算，擁擠取景只能盡量減少遮擋，並非保證任何拖曳縮放位置都完全無遮擋。標注只在錨點位於可見畫面時顯示；讀過的資料不另外增加收藏類別。
