## 1. 五人的提示階梯

第一層為頭部樣貌卡及一句面貌線索，不露店面背景；頭部圖須依基準版面裁切、清除周圍干擾。現有頭部原像素裁圖是依據，並非已完成去背素材。不把低像素臉部放大成虛假的高清；若辨認不足，後續另作標示「樣貌摹繪，原畫為準」的輔助圖，須待素材製作。

| 次序／人物 | 第一層：樣貌 | 第二層：玩家索取衣着／動作提示 | 第三層：玩家索取地標提示 | 請求區域提示後的範圍 |

| 1 紙馬鋪 B | 「戴低低的深色帽，臉略朝前。」 | 「他挑着擔，兩邊各有一只籃子。」 | 「在河岸店舖一帶，留意紙馬鋪附近。」 | 紙馬鋪及鄰近數間店面，保留兩邊行人與前景屋頂；不只框住挑籃人 |
| 2 酒樓 A | 「帽子低平，臉較朝向你。」 | 「他坐着，和旁邊站着的人不同。」 | 「入城後，留意門面結彩的酒樓。」 | 酒樓完整門面與街前人群；不縮到正店牌旁單人 |

## 2. 六段必經觀察與完成條件

各段「初看 → 史料 → 回畫」分步呈現。只有閱讀或按繼續不完成觀察；操作點中後才出一句理解。主要成功操作保留大於字詞本身的合理點擊範圍，手機須先近看，實際觸控尺寸未檢視。

| 段落 | 初看問題與操作 | 短史料之後回畫的問題與操作 | 完成條件／一句理解 |
|---|---|---|---|
| 紙馬鋪 | 「這間鋪子賣甚麼？」點店招，出店名輔讀 | 「商品怎樣擺給人看？」點店前陳列，保持形態可見 | 店招與陳列各看一次 → 祭祀、節令需求也形成專門生意 |
| 虹橋 | 「船上的人正忙着甚麼？」點船工動作所在的船段，近看後再看橋上人群，兩個焦點分步顯示 | 「船運與岸上的生活有甚麼聯繫？」史料後點一處橋邊攤販，讓船與岸上活動同在視野 | 船工、人群、攤販依序看過 → 河運與首都供應相連；不指定畫中這船貨物 |
| 酒樓 | 「這是甚麼店？」點正店牌，出詞註 | 「入口怎樣吸引人注意？」點彩飾門架，鏡頭保留店門及裝飾 | 正店牌與入口裝飾各看一次 → 店面、招牌可招徠客人 |
| 客店 | 「招牌說的是甚麼服務？」點久住招牌 | 「和酒樓有甚麼不同？」依次選回看客店與酒樓，各出服務短註 | 住宿店招已看，兩處比較已看 → 往來人口帶來住宿需求 |
| 香鋪 | 「店招告訴你甚麼？」點完整高立招牌，提供可核對文字輔讀 | 「哪些字說的是商品？」點招牌商品字詞段；依據來源釋讀，稱「沉檀」時標明是釋讀，不擴張為完整招牌定本 | 完整招牌與商品段各看一次 → 店舖可專營某類商品 |
| 醫藥鋪 | 「除了店名，還寫了甚麼？」先點店名 | 「這家店怎樣介紹本領？」讀醫鋪專科節錄後，點店名旁的治療宣傳文字，出可核對的輔讀 | 店名與宣傳字樣各看一次 → 城市有專門醫藥服務；書中專科不等於這家店的專科 |

這六段比 v0.2 更明確地分開兩次原畫操作，避免只是重複點同一處店招。虹橋增加船工與橋上人群的關係，仍以商業與供應為核心；不將撞橋原因、畫家政治意圖作必答結論。

## 3. 史料呈現的細化

史料來源連結及上下文沿用 v0.2。主線顯示短句，下一步依需要補一至兩個詞註；完整原文、白話、篇名及背景在見聞冊。

- 紙馬鋪：主線可節錄「紙馬鋪皆於當街……疊成樓閣之狀」，明示省略；完整句留在冊中。這讓必經觀察聚焦街邊展示方式，「紙袞」的校注核對仍保留為後續工作，不先編造詞義。
- 虹橋：保留東南糧與方物入京的短句。只須解釋「方物」「仰給」，分步顯示，讓畫面保持可見。
- 酒樓：以彩樓歡門句對讀實際裝飾；正店／腳店制度在冊中選讀。
- 客店：古文的安泊與畫中久住牌對讀；不判定眼前誰是外地商人。
- 香鋪：列舉不同專門店舖的短句；主線只要求讀懂原畫這間香鋪所營商品，不要求額外找到畫中未確認的珠寶或布帛店。
- 醫藥鋪：三處專科分散節錄逐一顯示，最後回看一處原畫宣傳。文字量較大時，主線先展示「口齒咽喉藥」「醫小兒」兩處，產科完整資料留在冊中選讀；這項縮短為新草案，尚未逐項確認。

本表均是遊戲虛構，依眼前姿勢及場面寫作，不自行確認職業。首次、再點與觀察後分開，下一段引路沿用 v0.2，再配合本稿的提示階梯。
