2026-10-21。使用者同意先完成「三位人物的尋找、原畫觀察、動畫與故事對白」串接。本輪沿用v0.10/v0.11人物動畫與既有共用介面，整理取景、對白及階段銜接；未新增正式章節入口或配樂。

## 完整路徑

引言兩幕 → 入畫自由尋找P1 → 找到短對白 → 玩家選擇近看 → 點原畫小犬 → 逗犬演繹 → 回到同一原畫證據及解讀 → 人物提供下一位線索 → 自由尋找P4 → 短對白 → 點原畫薄衣 → 舒袖演繹 → 原畫解讀 → 可選轉看執扇侍女並返回 → 下一位線索 → 自由尋找P6 → 短對白 → 點原畫髻花 → 斜首演繹 → 原畫解讀 → 女子收尾短對白 → 現有畫中回望 → 回看一處 → 自由探索。

下一位只更換樣貌提示與進度，不自動移鏡至答案。玩家仍需沿畫卷自行尋人；原畫觀察仍是動畫與故事解讀的必經操作。主線未要求收齊支線，既有收藏不清空。

## 本輪更動

- 新增獨立`zanhuaStoryFraming.ts`，為三位人物的原畫觀察及動畫後解讀保留題箋位置。P1左上題箋、人物與長柄／犬在其右側及下方；P4/P6題箋靠左，肩臂與髻花位於右側。
- 動畫播放前仍退至全人物演繹取景；結束、略過及載入失敗後先移除演繹層、回到原畫觀察位置，鏡頭停定才顯示解讀。不再直接把題箋蓋在全身動畫鏡頭上。
- 線索短對白期間隱藏尋人卡及探索工具，避免前一位的提示卡與人物對白同時出現。轉為下一位後恢復尋人卡與玩家原有凝神設定。
- P1線索改為「牠只顧我的手；你去看看拈花的那位。」；P4改為「盛裝各有安排。斜首的那位，也許有話問你。」。
- P6解讀後新增必經收尾短句「花與衣裳留在畫裡，名字卻沒有留下。」再由玩家進入回望，讓人物的身分提問接到全章。
- 侍女比較後也返回同一薄衣取景。其他人物短回應的位置避開實際題箋矩形，題箋展開及尺寸變化時同步量測。
- 鏡頭停定回呼改為只執行一次，停定即清除備援計時器；近看及繼續按鈕加上階段與轉場防重入。

所有題箋、按鈕、對白及圖示仍用現行共用元件與素材；新增CSS僅調整本章幾何位置。

沒有執行自動化測試、建置、全面裝置／瀏覽器檢查、減少動態及載入失敗情境模擬。其他共用章節未重新試玩。題箋避讓的非主線人物回應、合冊留白及窄屏配置未在本輪逐一操作驗證。
