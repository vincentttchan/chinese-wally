# 洛神全身原位演繹示範

> 本文件記錄 V1。現行版本已改為真分件並修正手機裁界與題箋，見[分件修正紀錄](luoshen-layered-figure-fix-2026-10-20.md)。

使用者指出衣帶顏色過淺，要求參照飛鳥製作過程，改為整位人物動畫。本輪以完整重繪人物取代先前只動衣帶的版本。

## 已完成

- 內建 imagegen 重繪完整洛神，保留原畫參考的髮式、手勢與飄帶，加深赭色、朱色、橄欖色及褐墨線。生成原檔及提示詞保存在 `public/art/animations/luoshen-figure/`。
- 頭部輕傾、上身微轉、手勢及垂袖各有動作，衣帶延遲跟隨；裙腳保持穩定。動作權重連續重疊，不是原畫人物像素變形，也不只是整張剪影旋轉。
- 人物直接放回原畫座標，沒有另建紙面舞台。暫時補底僅覆蓋舊人物輪廓，山石及絹底不作變形。返回原畫即移除全部重繪與補底。
- 沿用收藏、見聞冊對照、隔離試玩及獨立試看入口。保留重播、返回原畫、錯誤重試、取消清理、減少動態，以及與飛鳥互斥。
- 鏡頭改為完整人物：桌面放大比 1.6；窄螢幕為 1，以較高觀察中心避開下方題箋。具體裝置的遮擋仍待實機檢視。
- 畫作小記及演繹題箋更新為完整人物製作說明，保留原畫與生成演繹界線。

## 本輪實際驗證

- 11 項相關自動檢查通過：人物不同部位確有位移、裙腳穩定、補底邊界及旁側不變、透明人物原色不被多層透明度沖淡；圖片載齊才播放、完成／取消／失敗回復、減少動態、飛鳥與人物互斥、原畫對照／重播後能接續龍形與故事。測試使用 happy-dom，並非真實瀏覽器視覺驗收。
- TypeScript 檢查通過；本地服務 HTTP 200。
- 以實際動畫函式和原畫影像離線輸出 91 格，檢視完整人物及頭手局部的多時刻畫格。動圖、原畫與演繹靜幀保存在 `output/luoshen-figure-demo/`；不是瀏覽器錄影。
- 本機單純人物像素繪製取樣：502×585，50 次暖機後樣本中位約 8.15ms，95 百分位約 8.61ms。這只測函式，不代表瀏覽器合成、手機或整個遊戲幀率。
- 原畫 JPEG 沒有改寫。上一版單條衣帶素材及紀錄保留為設計歷程，已非現行播放內容。
