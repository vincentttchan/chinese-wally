# 亭內三人合奏群像樣段（第六版）

使用者指出單獨手部動作缺乏整體感，要求連同後方人物一起動畫。本版將鼓手、後方藍衣持鈸者、旁邊灰衣敲鑼者放入同一段合奏；原位播放入口保持 `#kangqu-ensemble-preview`。

## 現行效果與範圍

約 2.8 秒一次。鼓手先準備、起槌與落槌；持鈸者稍後合鈸；敲鑼者再接拍，三人各自收勢。三人的頭、頸、肩與上身分層參與動作，按各自腰部錨點小幅前傾、回彈，頭部另按頸部錨點點動。下身、座位與原畫位置固定，不做走動。

保留原畫頭部與上身紋理，配合新繪衣袖、手及器物姿勢；沒有顯示生成圖中的新面孔。鼓與建築維持原畫。演出開始/結束短淡入淡出，結束完全移除覆層。沿用既有提示卡、播放、重播、慢速細看、略過及 Escape。未改正式章節、見聞冊、收藏與進度，未推送 GitHub。

範圍是上述三人；畫面右側局部露出的吹奏者與更右方人物未納入此次群像。演出為遊戲演繹，不是歷史演奏復原。

## 素材與方法

原圖：`public/chapters/kangqu-listening/art/native-segment-lossless.webp`，原位裁圖 x=875、y=2275、240×295。

- 內建 imagegen 生成三人姿勢整張圖與移除人物的補底。
- 整張姿勢圖最右欄不完整，未採用；只取可用的手臂/樂器姿勢，不把整張生成畫面當原畫顯示。
- 原畫人物作為分層素材，身體繞腰部、頭部繞頸部轉動；使用手繪姿勢配合器物動作，不使用先前的逐像素拉扯方法。
- 原圖人物重疊、鼓與前後順序維持分層：補底 → 持鈸者 → 敲鑼者 → 固定原鼓 → 鼓手。
- 補底只用於移動後露出的邊緣；下身及腰部以下保留原畫，修正初版腰間露底的水平接縫。

素材與配準記錄：`public/art/animations/kangqu-ensemble-v6/`。
原始圖、完整生成提示詞與處理腳本：`output/art-direction/kangqu-ensemble-group-v6/generation.json`、`normalize.py`。
時序與身體/頸部動作：`src/game/kangquEnsembleGroup.ts`。
原位繪製：`src/components/KangquEnsembleAnimation.tsx`。

## 實際完成的檢視

在本機瀏覽器查看正常與半速演出。半速分段擷取時讀到：準備 blue:1/grey:0/drummer:2；鼓手下落 blue:3/grey:2/drummer:17；合鈸 blue:6/grey:3/drummer:7；鑼手接拍 blue:3/grey:6/drummer:9；收勢 blue:1/grey:10/drummer:1。

逐段查看擷取畫面，發現腰間補底接縫後，將腰部以下的補底限制移除，重新播放並擷取 `repaired-ensemble.png` 檢查該處。保留同目錄準備、起拍、合鈸、敲鑼及收勢截圖作歷程。

自然播放結束後回到提示卡；重播及略過後移除覆層，回到原畫。此次瀏覽器沒有記錄錯誤或警告。TypeScript 檢查與 Vite 建置完成，並打包本機首頁；建置仍有既有 bundle 大小提示。沒有新增或執行自動化測試，未檢視手機效能或實際減少動態裝置行為。

## 仍需使用者評價

這是分層人物與換姿勢相結合的 2D 樣段；小幅關節動作、器物姿勢切換與重疊邊緣仍可能看出製作方式，不能宣稱已達手繪影片自然度。完整表演的節奏與整體感仍待使用者實際觀看後確認。
