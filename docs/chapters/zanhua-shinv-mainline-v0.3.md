# 《簪花仕女圖》三人主線與短文案 v0.3

日期：2026-10-20。依據：[章節設計](zanhua-shinv.md)、[六人樣貌比較](zanhua-shinv-appearance-review-2026-10-20.md)。

使用者在看過六人比較與P1 → P4 → P6建議後指示「next」。本次沿此順序繼續具體化流程，不將此解讀為對未展示文案、動畫或全部實作細節的確認。

## 本章要讓玩家發現甚麼

在《簪花仕女圖》中尋找三位姿態不同的女子，從人物與小犬的動作關係、外衣的層次、髮髻上的裝飾，細看畫中呈現的貴族生活。

三段分別處理活動、衣料與裝扮，避免每次都點花或每次都講衣服。人物不冠上沒有依據的歷史姓名，不由其表情斷言心理，也不把畫中貴族女子的活動概括成所有唐代女性的生活。

## 引言與首個任務

引言兩步，由玩家推進：

1. 畫作背景：「《簪花仕女圖》描繪幾位女子與身邊的小動物。她們的衣飾和動作，藏着值得細看的線索。」畫作資訊另列「遼寧省博物館藏；傳為周昉作」，詳細年代與歸屬留在可展開來源。
2. 首位樣貌：「先找這位女子：她垂着頭，臉朝左下方。」配P1面部裁圖，主要操作「入畫尋人」。

保留原畫全構圖、玩家自行拖曳縮放及凝神開關。起始視角不自動對準P1；可先給包含多位人物的廣角，之後由玩家尋找。視角與題箋幾何位置留待沿用現行介面時安排。

## 三段主線完整流程

### 第一段：P1與小犬

- 第一層樣貌：「她垂着頭，臉朝左下方。」頭像使用原圖面部裁圖；不露全身、長柄物或小犬。
- 玩家要求第二層提示：「她身穿深色外衣，手中拿着一件長柄物。」
- 玩家要求第三層提示：「往畫卷的右半部找找。」只有再選「看看這一帶」才移至右半廣域；不圈人、不自動找到。
- 找到後短對白：「先別急着走，看看我手邊。」
- 主要操作：「近看動作」。玩家按下才移鏡。
- 觀察題箋標題：「她在和誰玩？」
- 點擊前提示：「順着她手中長柄的方向，輕點附近的小犬。」
- 完成操作：點中這一段的小犬，才登記觀察完成。點背景不完成，輕聲提醒「沿着她手中長柄的方向看看。」
- 點中後解讀：「長柄伸向小犬附近；小犬抬頭張口。把兩處連起來看，就能讀出人物逗犬的動作。」
- 點中後主要操作：「聽她說下去」。
- 下一段虛構對白：「再找那位臉較直立的女子。」
- 接續操作：「繼續尋人」。此時才啟用P4樣貌卡。

畫面事實：手中長柄物斜向小犬附近；小犬張口、頭朝人物方向。逗犬是對相對位置與姿態的解讀，不把畫面當作能確認聲音或實際運動的紀錄；不寫成小犬「正在叫」或已跳躍。物件正式名稱仍待核對，流程不依賴「拂塵」一詞。

### 第二段：P4與輕薄外衣

- 第一層樣貌：「她的臉較直立，稍向左轉。」配P4面部裁圖。
- 第二層提示：「她有一隻手伸在身前，拿着一朵花。」
- 第三層提示：「看看畫卷中段。」可選移鏡至中段廣域；不定位到臉。
- 找到後短對白：「我肩上的外衣，你看清了嗎？」
- 主要操作：「近看外衣」。
- 觀察題箋標題：「外衣裡透出甚麼？」
- 點擊前提示：「輕點她肩臂上的外衣，看看裡面還能看見甚麼。」
- 完成操作：點中肩臂的外衣區域一次即完成；不要求回答材質名稱，不切換成生成的「復原衣服」。
- 點中後解讀：「外衣的線條之內，仍看得見手臂和裡層衣色。透出的層次，讓這件外衣顯得輕薄。」
- 主要操作：「聽她說下去」。
- 下一段虛構對白：「還有一位，頭向另一邊斜着。」
- 接續操作：「繼續尋人」。啟用P6樣貌卡，卡上明示臉向右傾，避免只靠含混的「另一邊」。

本段只解讀可見的衣料層次，不判定纖維、織法、透氣程度、天氣或穿着感受。沒有把物件名稱問題變成知識選擇題。

### 第三段：P6與髮髻上的花

- 第一層樣貌：「她的頭向右傾，頸部也斜着。」配P6面部裁圖，先不展示完整頭花或旁邊花樹。
- 第二層提示：「她披着褐色外衣，一隻手抬在肩旁。」
- 第三層提示：「往畫卷的左半部找找。」可選移鏡至左半廣域。
- 找到後短對白：「髮髻上的花，也請你細看。」
- 主要操作：「近看髮髻」。
- 觀察題箋標題：「花開在哪裡？」
- 點擊前提示：「輕點她髮髻上方的花朵。」
- 完成操作：點中頭花一次即完成；點頭髮、臉、花樹或別人的花不代替本段操作，仍保留相應人物或收藏回應。
- 點中後解讀：「花朵簪在高髻上，旁邊還有細小髮飾。頭上的裝扮，也是觀察人物的一條線索。」
- 主要操作：「退後看全卷」。先完成本段觀察，才開啟收尾。

不把花定為某一品種，不判定鮮花、絹花或季節；也不使用P6指間尚待核對的小物件作主線答案。頭花解讀以原畫可見位置及簪花題材為依據。

## 畫中收尾

按「退後看全卷」後，文字先淡出，鏡頭退回包含六位人物的原畫。題箋短文案：

> 手中的動作，讓人物與小犬有了呼應；衣料的層次與髮髻上的裝飾，讓我們看見更多生活細節。

提供「回看一處細節」作最後一段畫中探索：玩家選「人物與小犬」「輕薄外衣」「髮髻上的花」其中一處，鏡頭回到相應原畫，顯示該段已完成的一句發現，按「留在畫中」後主線標為完成。三處任選其一，不要求全部重看或收齊收藏。

接着保留「自由探索」「見聞冊」「再尋一次」。不添加畫法教學、知識測驗或獨立結業頁。回看選單、題箋、完成入口沿用基準元件語彙；選單幾何位置仍需效果階段安排。

## 狀態與共用介面的接入要求

- 逐段狀態：`searching → found → observing → observationComplete → nextClue → searching`；第三段完成後改為`epilogue → recall → complete`。
- 成功找到只標記找到，不代替原畫觀察；第三位同樣需要觀察。本次讀到基準 `LanternDiscovery.tsx` 的第三次人物流程會直接進入收尾，不能照搬這個分支來跳過本章第三次觀察。
- 近看由玩家按鈕觸發；轉場期間避免重複操作，停定後恢復點擊。保留玩家的凝神／彩色設定，不自動以灰階替代第二段的衣料觀察。
- 原畫觀察熱區優先於該處人物熱區；點錯其他可互動人物仍有短回應，不扣分、不直接揭曉答案。
- 收藏與主線完成分開：同一小犬或頭花兼具收藏時，一次點擊可完成當前觀察並登記收藏；人物對白、收藏動畫、題箋依序顯示，避免相互遮擋。若收藏早已取得，之後仍需完成主線的這次觀察；重複收藏不增加數量。
- 四類收藏仍為候選。本次沒有補齊全部重複位置，不宣稱收藏盤點完成。
- 按現行尋人卡、人物對白、畫旁題箋與見聞冊的素材和樣式實作；本文件未授權另造一套效果稿介面。
