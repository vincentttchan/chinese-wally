# 宮中鬧元宵：三幕入場獨立版本 1.0.0

2026-10-27（香港）｜狀態：本機可玩版，未部署。

使用者已確認兩幅畫的三幕入場與對齊效果，要求將入場接入章節流程並另存新版本，同時明確指定《在人群中聽樂》仍在審視，完成後才通知更新。因此本次只接入《宮中鬧元宵》；康衢的正式新版與入場樣段均不修改。

## 新版本與保存基準

- 版本識別：`lantern-three-act-v1`，版本 `1.0.0`。
- 完整可玩入口：`public/chapters/lantern-three-act-v1/index.html`；版本與來源指紋在同目錄 `version.json`。
- 開發入口：`lantern-three-act-v1.html` → `src/lantern-three-act-v1.tsx`。
- 封裝與檢視記錄：`output/releases/lantern-three-act-v1-2026-10-27/`。
- 正式封存 `site-2026-10-23` 與 `site-2026-10-23-zanhua-navigation` 保留，沒有移動 Git 標記或改寫封存文件。
- 原有 `LanternGame.tsx`、主路由、`public/index.html`、共用場景、音樂與收藏邏輯未修改。新章節控制器為現行 LanternGame 的獨立副本，只改封面進場及交接，沿用現有尋人、原畫觀察、人物回應、演繹、見聞冊、收尾等元件。

## 實際流程

原有封面及底部章節名稱導航 →「走進這一卷」→ 宮中元宵 → 畫中元宵 → 初次隨行 →「入畫尋人」→ 原有的可操作長卷、人物樣貌提示與凝神觀察。

三幕文字完整沿用已確認的 `output/design-preview/lantern-entry-2026-10-27` v0.3 樣段。小內侍身份與對白為遊戲虛構；畫作背景來源沿用樣段中的中國國家博物館資料，沒有新增歷史主張。

主畫面使用七欄固定網格、相同頂線與每幕相同的右側起筆位置；每字約110ms、淡入220ms，標點及欄末稍停。背景原畫連續向右緩移52秒後停下，三幕之間不重置。可暫停畫卷、顯示全文、前往前一幕；系統減少動態時顯示全文並預設背景靜止。

最後一步等待實際章節的原畫與全部局部載入完成，將入場最後一刻的相機位置交給遊戲場景，再淡去入場約1100ms，顯示原有尋人介面。沒有展示樣段的假結束頁，沒有多出第二套尋人狀態。進度與收藏沿用本章現有規則。

「回到本章封面」透過原有共用轉場回到新版封面，重新進入時重播三幕，保留本章收藏。跨章名稱導航交回原有遊戲入口；本次沒有更改其他章節。

## 原畫、樣貌與音樂

原畫全卷及高清局部直接使用 `src/game/lanternFestival.ts`、`lanternScrollPlacement.ts` 的既有檔案與投影，來源見 `public/art/lantern-festival/SOURCES.md`。沒有生成、補畫或重存原畫。

字體、透明細線操作、白色手繪箭頭與三幕的文字樣式沿用已確認樣段。入畫後使用既有手繪圖示、提示卡、人物對白及見聞冊。背景配樂仍由 `useAmbience` 與既有音樂開關控制，曲目及署名保持原樣，沒有自動播放。

## 封裝方法

```sh
npx vite build --config vite.lantern-three-act-v1.config.ts
node scripts/package-lantern-three-act-v1.mjs
```

這是獨立建置，不執行全站 `npm run build` 或 `package-local-home.py`，不覆寫既有本機入口。版本頁將已編譯程式和樣式內嵌，原畫／音樂／字體等檔案以相對路徑沿用 `public/` 目錄，可由本機靜態伺服器開啟。
