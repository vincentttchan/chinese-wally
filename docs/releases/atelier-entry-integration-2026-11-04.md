# 夜訪畫坊主站整合

主站首頁採用已確認的《夜訪畫坊》v19。網頁入口在 `public/atelier/index.html`，原畫作連結仍由原有章節路由處理。畫坊內的簪花與洛水使用主站章節，簪花只在畫坊旅程中啟用章末回望與自選留印。

旅程按簪花、宮中、康衢、洛水的次序開放。宮中旅程版取自《宮中鬧元宵》0.1.8，康衢旅程版取自《在人群中聽樂》2.3.1，並沿用 v19 已試玩的作答與解鎖流程。洛水的章末收藏條件留待章節定稿。

觀畫帖由章節完成進度推算。主站在本機找不到新進度時，沿用同一瀏覽器的 v19 預覽紀錄。宮中旅程版另存主線進度，首次進入時可讀取既有存檔。各章的圖像和遊戲內收藏仍沿用各自的素材及存檔格式。

本機由首頁走通點燈、點印及簪花封面。以簪花章末的測試進度核對自動收藏、解鎖宮中、重開續玩、重訪舊卷及原有簪花網址。
