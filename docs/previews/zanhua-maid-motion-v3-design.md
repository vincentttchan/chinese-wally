# 侍女手腕及揮扇修正 v3（2026-11-13）

使用者指出 v2 手腕及揮扇仍然突兀。本次只修正動作連動，保留原畫位置、分層素材、鏡頭、敘事、收藏、章末及全螢幕返回。

## 根因與改法

- v2 由扇子指定兩隻手的位移，再解手臂關節。手掌與扇固定，但前臂另轉，抬扇側手腕轉角相對原姿勢最高約 34 度。
- v3 改由抬扇側上臂、前臂正向帶動，前臂、握持手掌、整把扇使用同一剛性旋轉；此側手腕不再另彎。另一側保持兩節手臂長度並承托扇柄，相對原姿勢的手腕轉角最高約 9.99 度。
- v2 在每一個中間關鍵姿勢使用零速度／零加速度插值，造成多次停頓。v3 使用帶整體起落包絡的連續往返曲線，中間位置不再停下再啟動。
- v1、v2 動作模組、既有素材和入口模組均保留；新增 motion v3 模組和兩個版本入口。主 renderer 及本機畫坊入口引用 v3。
