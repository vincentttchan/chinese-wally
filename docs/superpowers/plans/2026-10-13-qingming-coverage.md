# 清明上河圖人物與同類線索覆蓋計劃

**目的：**依使用者要求，逐段完成目前原畫影像中可辨識人物及商業／運輸線索的盤點，接入現有遊戲短回應與收藏去重。
**依據：**`docs/historical-painting-chapter-standard.md`、已確認清明章節及使用者本次指示。
**方法：**三個互不重疊畫段獨立目視盤點；人物逐一記錄像素矩形與三句虛構對白，遮擋／低清例外逐一說明。原畫不改寫，輸出可核對的標記局部。主線人物沿用 ID，集體觀察框與個人熱區分開。

- [x] 目視盤點 x0–12000 城內與城門；保存人物、店舖、招牌、運輸物件及排除表。
- [x] 目視盤點 x12000–24000 河岸與虹橋；保存船上與橋上各人物及重複線索。
- [x] 目視盤點 x24000–38414 河岸、郊野；保存所有可辨識人物與商業／運輸線索。
- [x] 統一核對跨段接縫、主線人物重複、坐標和不確定判讀；保存完整覆蓋表與對白表。
- [x] 接入逐人／逐物回應，保留主線守衛；原畫觀察點錯也有短回應，不能推進任務。
- [x] 接入同類收藏全部已確認實例、首次位置與重複通知；物件小熱區不被集體／人物大框吞掉。
- [x] 編譯打包、實際代表畫面檢視與記錄限制。遵從 AGENTS.md，不新增／執行未要求的測試。

保持《宮中鬧元宵》現行介面及完成章節；沿用現行原畫與音樂。全画覆蓋指本影像可辨識實例的逐段盤點，不以坊間人物總數替代觀察，不宣稱不可见／模糊人物已辨認。沒有來源支持的店舖類型只稱店面／招牌，不觸發特定行業收藏。

## 完成紀錄

合併後698個人物／待核位置（693互動、5待核）、224個物件／觀察位置（222互動、2不作商業互動）。現行資料、54段SVG與對照工具已產出；37收藏位置維持六類去重。TypeScript、Vite不複製public的程式打包及本地包裝完成。实际查看新增人物／棚台回應、原畫觀察守衛及重複收藏通知，保存最後對白避讓效果。沒有新增／執行測試套件，也未逐一點遍或作裝置驗收。詳見 docs/chapters/qingming-coverage-2026-10-13.md。
