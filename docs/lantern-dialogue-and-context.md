# 畫中人物對白與背景交代

2026-10-08；入口 `/#lantern-festival`。

## 入畫前

保留兩幕、玩家自行前進的引言。第一幕交代《憲宗元宵行樂圖》描繪明憲宗在宮中慶賞元宵；第二幕才交代辨認眉眼、尋人與留意旁人活動的任務。不在開場解釋皇帝重複出現的構圖意義。

背景依據：[中國國家博物館元宵專題](https://www.chnmuseum.cn/portals/0/web/zt/202102yuaxiao/)。本次核對館方對畫作年代、作者佚名、絹本設色及三段宮廷元宵活動的介紹；沒有把虛構對白當作史料。

## 人物回應

- `src/game/lanternDialogue.ts` 連同 `src/game/lanternExtraPeople.ts` 定義 177 組人物聲音，每人三句，共 531 句；本次新增 111 位。
- 首次一句招呼；其後交替兩句同一人的回應。重新尋人會重設訪問次數，見聞收藏仍保留。
- 依全卷 17 張原畫局部的可見姿勢、器物和場景寫作；內部情境描述不是已考證的人物身分。
- 主線皇帝首次尋得仍進入原有的必經觀察及線索對話。其他點選使用各自的短回應，並非共同的三句隨機池。
- 保留 16px 楷體單行美術氣泡及指向人物的尖角；一般回應三秒淡出。
- NPC 對應收藏支線時先回話，氣泡提供「細看」按鈕，玩家選擇後才進入原有收藏觀察。這種氣泡保留至細看、再點選、拖曳或 Escape，給玩家足夠操作時間。
- 鍵盤觸發支線回應時把焦點送至「細看」；減少動態偏好停用氣泡動畫。
- 細節本身的收藏熱點保留原有流程；目前可點選人物是已定位的 177 人，並非全卷每個繪出的人物。
- 對白統一於畫作小記與無障礙標籤說明為遊戲虛構。

## 入畫後及完成時

保留三次必經觀察與結尾的回看三段、選擇細節證據、認識連環畫式構圖及工筆式描繪流程。完成頁有收藏時增加「回看我收下的 N 則元宵見聞」，連到已選定 B 版見聞冊，讓個人的發現與解說接起來。
