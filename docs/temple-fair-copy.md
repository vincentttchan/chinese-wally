# 廟會尋蹤文案

## 引言

1. 廟會正盛：戲棚開唱，貨郎叫賣。／滿街都是趕會的人。按鈕「走進此日」。
2. 便服之中：今日，皇帝也混在人群裏。／隨行的人都換了尋常衣裳。按鈕「聽他的委託」。
3. 悄悄尋君：「請替我辨認陛下，別驚動百姓。」／傳信侍從向你低聲求助。按鈕「入畫尋君」。

卷末小語：一場廟會，藏着一位尋常衣着的天子。

## 任務與證據

任務：悄悄辨認微服的皇帝。

未錄齊：廟會裏的人與物，或許留下他的痕跡。觀察動作，也留意攤上的小物件。

錄齊：三條線索已錄。比對衣袖、摺扇，以及看客彼此之間的關係。

餅攤婆婆／人物證詞／沾粉的衣袖：「方才有位拿摺扇的客人，替孩子撿起滾到攤下的竹球。右邊袖口沾了麵粉，也沒有急着撣掉。那扇子像是剛補過。」

補扇樣本／物件細節／青線補痕：桌上的白色摺扇，一根扇骨纏了青線。這是攤主的補扇樣本；修補過的摺扇會留下同樣的小痕。

戲棚旁的看客／現場觀察／目光所向：戲正唱到熱鬧處，這位看客卻側頭望向人群。另一邊也有一人如此；兩人的目光留意着同一位客人。

未錄項目：線索一／二／三・待錄；尚未記錄線索；人物與物件裏，或許藏着一點端倪。來源名字、角色圖像與線索型態在取得前隱藏。

## 提示

餅攤：留下痕跡的小事，攤主常會記得。／看看有人買點心、孩子玩耍的地方。／已展開食攤一帶，留意做餅的婆婆。

補扇：一件修補過的物品，會留下甚麼痕跡？／手藝人的桌上，或許擺着供客人查看的樣本。／已展開補扇攤一帶，看看桌上的摺扇。

看客：看戲的人，目光應該落在哪裏？／戲棚前，留意側頭看向別處的人。／已展開戲棚附近，觀察看客的目光。

皇帝：衣袖、摺扇和看客的視線，要放在一起判斷。／找到相似衣袖與扇子後，再看看誰在暗中留意他。／已展開看戲的人群，將三條線索交叉比對。

## 結局

人群中的天子：青線補過的摺扇、沾粉的右袖，以及兩名看客的目光，都指向這位青灰衣人。你悄悄示意，傳信侍從上前行禮。他收起摺扇，仍低聲問着攤主今日的生意。

## 閱讀

標籤：廟會小知識。標題：廟會裏，除了上香還有甚麼？

廟會往往依託祠廟，在特定時日舉行。人們聚在一起，除了祭祀祈福，也可能交易貨物、欣賞表演。

以上海龍華廟會為例，小食與娛樂表演都是重要內容。攤販售賣當地食品，人們也可看皮影戲、花鼓戲等表演。

因此，畫中的香客、餅攤、手藝人與戲棚，可以同在一場廟會裏。各地廟會的時節與習俗有所不同，內容也會隨時代改變。

註記：本關廟會、皇帝與尋人案件均為虛構，畫風參照《清明上河圖》。閱讀以實際廟會資料介紹民間生活，並非還原某位皇帝的行程。

題目：依照文章，哪一組活動可能同時出現在廟會裏？

- 只有上香，沒有其他活動。
- 祈福、買賣貨物與欣賞表演。（正解）
- 只有科舉考試與公布榜文。

解說：廟會可包含祭祀祈福、商貿與娛樂活動。畫中的香客、攤販和看戲的人，正好呈現不同活動聚在一起的景象。
