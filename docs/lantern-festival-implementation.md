## 遊戲內容

- 真實歷史畫作《憲宗元宵行樂圖》的完整長卷，作連續可拖曳主場景。從右端開始，三個庭院都可以自由探索。
- 底圖9781 × 651；17張原畫局部經可見特徵定位，以CSS投影疊放，補充細節。沒有補畫或生成歷史人物。缺少較高像素局部的區域保留全卷底圖，清晰度並不完全一致。
- 預設凝神，玩家可切換全彩。最小縮放保持cover，不露上下背景；全卷的其餘部分延伸在視窗左右。
- 底部導覽顯示目前視窗範圍，可拖動位置滑桿或點庭院名稱移動。僅導覽縮略圖同時顯示全卷，主畫面保持可以辨認人物的比例。
- 三次尋找同一位明憲宗，分別在第一庭院觀看爆竹、第二庭院站着觀賞宮中街市、第三庭院坐着觀看表演。
- 每次只顯示當前人物局部。找到後保持原來視角，在原畫人物旁顯示一句歷史發現，再由玩家點選近看，進入必經的短觀察；每一步只呈現一句重點。
- 三次必經操作依序為：切換灰階看衣紋、標出高台與庭院作對照、回看三處原畫身影。只有完成當次操作才出現一句回饋及繼續按鈕；沒有選擇題或對錯評分。
- 不在完成一次尋人後自動移到下一個答案；保持玩家自己探索。主動提示可逐步增加人物範圍、文字，再移到大致區域。
- 第三次觀察已比較三處皇帝，結尾直接在原畫上顯示一句總結，之後可回畫中自由探索。每次新目標及重玩會重設觀察操作狀態。
- 完整畫法與宮廷歷史解說收進畫作小記的「三次觀察筆記」，可自行展開；古風音樂由玩家開啟。

### 比較頁字體與位置修訂

- 對白預設改用 LXGW WenKai TC（霞鶩文楷 TC），字型隨網站載入，避免外部字型連線失敗；只用於比較頁，可切回宋體。字型來源：https://github.com/lxgw/LxgwWenkaiTC ，OFL授權隨附於 public/fonts。
- 預設字級26，提供20–30的字級滑桿；行距縮至1.55，縮短姓名、對白、操作之間的間距。
- A移到人物身旁的高度，縮短連線；B字幕上移至畫面較低處，不再貼近底邊。
- 字體與字級在切換A／B時保持一致，方便使用者判斷。

## 完成尋人後的必經深化

- 原本一句式結尾改為兩步：三次身影的敘事判讀、從畫中選取細節證據。兩步完成後才提供自由探索及重新開始。
- 第一步提供三個原畫人物局部，可點擊回到對應位置；答對關係後揭示「連續敘事／連環畫式構圖」。回答未合適時留在題目，提示比對衣着與活動，可再次選擇。
- 第二步回到彩色原畫，從衣袍紋樣、建築細節、人物動作中選一項證據。三項皆為有效觀察，選取後形成「我認為……因為我看到……」並解釋工筆式描繪、絹本設色。
- 結尾期間顯示彩色原畫，說明灰階為遊戲觀察工具；返回自由探索後恢復玩家原先模式。回看及近看由玩家點擊觸發。
- 完成後的小結列出畫法、敘事、宮廷生活三項發現；魚形燈／象形燈寓意及宮廷圖像的史料範圍放在可自行展開的延伸探究。
- 閱讀沿用20px楷體，無彈窗紙框，依人物位置安排畫旁文字。較小視窗可捲動閱讀；鍵盤焦點留在當前步驟。重開「長卷的秘密」直接回到完成小結，重新尋人才重設深化進度。
