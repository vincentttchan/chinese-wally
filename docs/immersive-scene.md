# 滿版畫卷更新

## 方向

以古畫作為整個遊戲的主視角，場景佔滿視窗。初始鏡頭從榜牆開始，畫作以 cover 尺度直接填滿網站視窗，長卷向左右延伸；拖曳探索各段人物，縮放用來觀察細節。「回到卷首」返回起點。縮小下限亦維持滿版，沒有上下或兩側色塊留白。

- 色彩：紙箋 #f5efdf、墨 #353c32、竹青 #485a47、印泥 #954c37、長卷底色 #c6b18a。
- 字體：Noto Serif TC、Songti TC，任務文字小而可讀；標題只留在開場。
- 佈局：左上角任務，右上角場景設定；左下角收起的線索簿，右下角提示。平時畫面中央及下方中央留給畫中人物。
- 開場委託短，入畫後消失。桌面證詞紙箋靠近人物，手機用下方紙箋。線索簿為非模態紙頁；知識與遊玩指南採原生 dialog。

紙色、宋體與印泥是古画題材本身的材料選擇；不另加全頁標題、頁尾或常駐線索卡。

## 聲音

預設關閉，玩家點擊聲音按鈕後啟動 AudioContext。低音量人群聲持續播放；五步一組的腳步與倒茶聲間歇出現。證詞或線索簿開啟時降低音量；頁面在背景時靜音。素材下載失敗提供重試。

來源及公有領域資訊見 `public/audio/CREDITS.md`。錄音用於虛構場景的氛圍，而非歷史聲音重建。

## 微動

SVG 圖層與原畫共用世界座標及鏡頭變換：河面光紋緩移、茶壺蒸汽慢慢消散。旗幟使用原畫本身的布幡，不再疊加會造成重影與錯位的局部扭曲圖層。圖層不接收點擊，人物與線索保持靜態。可獨立關閉；尊重系統減少動態效果的設定。

## 開發記錄

沿用原有案件與 reducer，人物座標按目前全景古畫重新校準，未新增或執行測試。正式建置執行 TypeScript 檢查與 Vite 打包。

## 第二輪：全景與閱讀節奏

使用者已確認全景尺度可直接點選人物，放大屬可選工具。美術繼續沿用《清明上河圖》的細線、淡彩、古絹質感；截圖只作介面與構圖參考。

- 任務紙箋整合 0/2 線索進度，首次探索後約兩秒收起，可點擊再次展開。
- 右上只保留聲音、全螢幕及更多設定；縮放、全卷與微動在更多設定內。
- 進場依序淡入画作、紙箋、操作與線索簿；操作立即回應，敘事過渡較慢。
- 縮放階段為 100%、110%、125%、150%、175%，中心跟隨滑鼠或雙指中點。拖曳慣性最多 28px、約 220ms。
- 問訊證詞使用場景附近的紙箋；線索簿為左下角非模態冊頁，允許繼續觀畫。
- 點錯只有 1.4 秒的文字回應；提示提供文字方向與短暫柔和區域光感，不畫圈或大箭頭。
- 找到考生後輕微聚焦、朱印「尋得」、短暫停留，再顯示重逢結局。可略過。
- 結尾提供可自行打開的科舉知識，內容以清代殿試作例子，附故宮博物院及文化資產局來源，明示虛構故事與制度說明的區別。
- Reduced motion 停用鏡頭動畫、慣性和場景微動；保留可讀的結果與朱印。

動態 token 統一為 120、180、260、380、550、950ms，對應即時、快速、一般、紙箋、鏡頭、敘事。

## 第三輪：全景與點陣介面美術

16:10 全景古畫已生成並接入。所有介面圖示換為手繪點陣圖集，紙箋使用生成美術及九宮切片，證人小像直接取自畫作。剩餘 SVG 僅用於極淡的河水、蒸汽微動，不承擔資訊介面。生成提示與素材紀錄見 `docs/art/README.md`。

## 第四輪：恢復滿版長卷與先審閱局部樣稿

使用者否定單幅 16:10 城市全景，要求左右展開的長卷氛圍與網站開啟即滿版。網站恢復原有 3:1 長卷、其人物座標及微動位置；保留點陣介面美術。鏡頭下限改為 cover，Home 及回到卷首亦使用 cover。視窗尺寸改變時保留目前閱讀的位置，在卷首與卷尾則保留端點。

新美術先製作榜牆與茶攤的局部方向樣稿：小而相近尺度的人物、清晰墨線淡彩、重複特徵、密集生活小故事。該樣稿供討論人物密度及筆觸，完整新長卷仍待樣稿方向確定後延伸。
