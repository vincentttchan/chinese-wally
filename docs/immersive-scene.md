# 滿版畫卷更新

## 方向

以古畫作為整個遊戲的主視角，畫卷滿版，先展示榜牆附近的街景。移動和縮放探索完整長卷。「覽全卷」是使用者主動選擇的遠景模式。

- 色彩：紙箋 #f5efdf、墨 #353c32、竹青 #485a47、印泥 #954c37、長卷底色 #c6b18a。
- 字體：Noto Serif TC、Songti TC，任務文字小而可讀；標題只留在開場。
- 佈局：左上角任務，右上角場景設定；左下角收起的線索簿，右下角提示和縮放。平時畫面中央及下方中央留給畫中人物。
- 開場委託短，入畫後消失。桌面證詞紙箋靠近人物，手機用下方紙箋。線索簿採原生 dialog 保留焦點管理。

紙色、宋體與印泥是古画題材本身的材料選擇；不另加全頁標題、頁尾或常駐線索卡。

## 聲音

預設關閉，玩家點擊聲音按鈕後啟動 AudioContext。低音量人群聲持續播放；五步一組的腳步與倒茶聲間歇出現。證詞或線索簿開啟時降低音量；頁面在背景時靜音。素材下載失敗提供重試。

來源及公有領域資訊見 `public/audio/CREDITS.md`。錄音用於虛構場景的氛圍，而非歷史聲音重建。

## 微動

SVG 圖層與原畫共用世界座標及鏡頭變換：河面光紋緩移、茶攤原有旗幟極輕擺動、茶壺蒸汽與煙氣慢慢消散。圖層不接收點擊，人物與線索保持靜態。可獨立關閉；尊重系統減少動態效果的設定。
